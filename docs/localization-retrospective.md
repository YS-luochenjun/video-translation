# 视频本地化会话复盘与知识沉淀

2026-11-02复盘。核对23个近期制作聊天与既有056最后日语V3，进一步审查24条实际反馈来源、17组独立案例manifest的104个文件，并查看必要的原尺寸对照。聊天自报、技术通过、模型感知、选定静帧与完整视听验收分别记录；未将本次研究表述为全部视频质量通过。详细会话和原始证据保持本地。

## 执行方法

1. 从真实源片建立文字/人声逐实例清单，保存样式、布局、运动和保留理由。
2. 为代表性困难区选自然去字路线；图片优先ImageGen，连续复杂修复评估Wan，遵守原预算和返工次数。
3. 先验证共用底片的文字效果范围、主体、切镜及片尾，再扩语言；普通瑕疵在有界结束后披露，不因质量分数独自停交。
4. 各语言独立定稿、角色配音与混音对齐、物理字体/艺术字和原位动画，核对完整编码短语及相邻组合。
5. 原片/底片/译片对照，以实际视频哈希绑定视觉、声音与字幕证据；检查入出场和最后解码帧。
6. 完成既有固定提交，核对全部原片×目标语言矩阵；保留内部质量结论、例外和剩余项。
7. 保存修复前后、未改区、漏检原因和限定观察。相同动作关联现行方法；源限定事实入案例；缺证据保留具体下一步。

## 本轮落地与边界

- 升级现有多语种复盘到第二版，第一版索引标为被替代；为旧案例链接保留原文字节，正常检索仅加载第二版。
- 新增2条私有同源同语种案例：印地语整句裁边；德语界面标题与证据范围。图像与原始业务反馈不放入公共报告。
- 24条来源完成审查，2条以限定案例结清，其余22条保留部分采纳/具体补证；公开派生候选完全吸收后按指纹归档。部分记录的因果表述比所选图能证明的范围大，已收窄审查结论，旧原文保留。
- 未增加新质量门槛、默认遮罩路线、付费强制步骤或跨范围验收；没有重新制作或上传历史视频。此次没有将临时YouTube排障/清理过程写成知识，既有上传规则保留。

## 仍需继续吸收

截至本轮维护地图，队列有337条记录，归为127个浏览家族；其中207条是自动占位复盘，130条含实质待审内容。家族只是导航，不合并不同语种或验收。不能声称337项都已有独立可复用结论，也不应按数量批量关闭。

现有闭环为：制作/反馈记录 → 候选 → 有证据的审查 → 现行方法或限定案例 → 实际使用反馈 → 反例/修订。独立经验任务按到期窗口运行；每次收尾仍主动看knowledge-queue、hooks status、pending及使用反馈。enabled或归档数量不证明知识效果，后续真实任务继续反馈。

## 共性问题的工程修复（2026-11-02）

将上述观察落实为[渲染与取证防错](../knowledge/rules/native-render-evidence-guards-v1.md)：绑定字体按哈希隔离实际字面；静态排版纳入最外描边、阴影和字形边界；清底三方对照补原生区间外各一帧；必需人声报告的明确缺失与complete结论发生矛盾时报错。新增回归覆盖这些缺口，并以新的本地合成视频验证字体合成和边界取证，未调用付费模型或重做客户视频。

这些修复减少可复现的机械错误；不自动完成自然去字、角色听审、所有文字时机或全片画质验收。真正效果仍由后续需求的原片/底片/译片和实际声音反馈验证，普通瑕疵下的有界完整提交规则保持。
