## 分轨与独立配音试验（2026-10-19）

以下保留当时的观察及局限，当前调用入口以模型路由为准。


`model-task RUN inputs/<packet>.json` 预览来源绑定的请求，加 `--execute` 才真实提交；分离、TTS、短片试验共用原运行的任务笔数与费用账本。`poll` 保存所有返回音轨、供应商名称、哈希和费用。网络结果未知先对账，不因更换 CLI 名称而重新计费。

本次实际调用 Suno `split_stem` 得到12轨，去掉 Lead Vocals，保留 FX、Backing Vocals 等其余轨；按实测约47ms延迟对齐后回混，末尾无对白段恢复原混音。该分离过程可能损伤人声型音效或残留外语；不能将“存在 FX 轨”视为音效完整保留。

Gemini TTS 使用 `Speaker1`、官方枚举参数和合并后的完整中文稿。首次同一说话人多条对话只返回约5.4秒，改为单条完整文本后得到约22.1秒；时长仍不能证明内容完整。五段旁白按源句时间窗口分配，最后 CTA 加速，所有裁切、增益、速度与源模型任务保存在 `mix-provenance.json`。ElevenLabs 两次内部500失败为0 credits，不误报为连接或鉴权失败。

`bin/asr.py RUN` 可对 `capture` 的实际 WAV 做本地多语种识别；不传预期中文稿，保存实际语种、分句、模型与音频哈希。`--audio` 可检查另一个真实运行音轨，例如分离后的背景轨。ASR 可支持对白覆盖判断，不能证明发音、音乐音色、全部音效和口型合格。本次中文五句已识别，背景轨未检出人声；背景音乐与音效完整性仍待听审。

付费音频理解的原始响应和计费回执必须先保存，再解析业务 JSON。本次曾因反向顺序丢失无效回复的原始内容，已加回归修复；旧回复无法恢复，保留费用未知与未验收状态。声源分离、TTS 与本地 ASR 是已执行过的实验链路，口型对齐尚未集成，未宣称真实广告已全面验收。
