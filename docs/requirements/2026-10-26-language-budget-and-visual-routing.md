# 多语言预算与文字修复修订

来源：2026-10-26项目用户明确要求“多语言可以增加预算……60credits每一个都行”，并询问可见模糊是否因为预算太少而取代Wan视频编辑；后续要求调研KIE模型库性价比。此需求替代此前新请求按源时长×3的预算偏好；历史原话、账本及未结费用保留。

新首次/新复用请求按实际规范化去重目标语言数×60 credits建立共享总池；共用去字底片可跨语种复用，不对各语言再设硬分区。登记targets是主控内部操作，不增加用户确认。新增语种用有真实用户来源的budget-amend修订targets和总额，保留已花费与未知预留。未指定旧请求，不批量改写历史账本或现有逐单授权。

静态底面自然重建；复杂运动/遮挡基于实际连续帧评估Wan 2.7连续局部编辑，不因省额度默认模糊。保留已有两轮返工与逐实例质量门禁；模糊须有实际候选或主体风险依据。此为选路修订，不是新视频实验或质量认可。

执行入口：config/budget-policy.json、budgets.request_allowance、budget-open、budget-amend、batch-create、workflow.execution_limits。新请求需真实targets，别名/大小写重复不增加额度，明确不同地区标签保留。任务名额仍按原视频分段/角色有限规划，不能再被默认每run两笔限制压住。旧source_duration计算与固定60/40只供历史兼容。

模型调研记录在docs/research/2026-10-26-kie-video-edit-value.md；只读研究不授权付费实验，也不改变现行视频路由。Fireplay后续集成条件见docs/fireplay-localization-integration.md。本次不接取或回写平台需求，不创建持续运行服务，不提交或推送Git。
