# Codex 主导与实用质量版本

来源：项目用户于2026-10-23要求扩大 Codex 自主执行范围、约束 ASR/TTS/Wan、降低轻微视觉瑕疵严格度，并清理无用半成品和空目录。

用户进一步要求所有后续任务必须输出最终翻译视频。新增 `finalize RUN`：在预算和返工边界内选当前最佳完整视频，保留评分/失败原文，以“已输出/有瑕疵”归档和展示；配音不可用时采用完整目标语字幕。详见 [最终输出工作流](../../agent/workflows/always-output.md)。

Codex 决定内容、翻译、图片方法、排版、模型输入、采用范围和返工；Whisper、UVR、Gemini 和 Wan 只承担对应音视频工作。连续运动编辑可直接选择 Wan，无须先试尽图片方法。约束和检查见 [模型合同](../../agent/contracts/model-routing.md)。

综合评分门槛从85调整为80；默认快速模式以正常播放为依据，视觉精致度3/5可接受。轻微纹理、颗粒和接缝可以带说明通过；漏译、明显残字、主体/图形损坏、动作异常、音频缺失或不同步仍需修复。新标准不修改旧验收记录，详见 [质量合同](../../agent/contracts/quality.md)。

新现场按需创建目录，工作包直接列出按源哈希核验的 outputs 复用包；无用现场先保全再删，过时版本保留必要反例。未知费用、活动任务和被引用资产保留。具体本机清理结果写在 state，不作为长期文档中的固定数量。

验证范围为执行器、配置、文档与本地合成回归；本次项目修改不提交付费模型、不宣称真实广告或母语音频已验收。源码通过 workspace-export 导出，不包含凭据、旧视频或安装权重。

## 每次运行的增量整理

新增 maintenance 配置和 CLI/MCP 入口，成功阶段自动检查本任务普通空目录，交付后按登记哈希与引用清理可重建缓存；结案执行 maintain --close，保全并验证独立包后按预览指纹退出制作现场。未结算费用、活动任务、被引用文件与正式 outputs 包受保护。work-packet 返回整理状态和具体结案命令，清理失败不阻断视频输出。
