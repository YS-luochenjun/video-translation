# 存储上限与保留策略

推荐“精简保留内容 + 数量/容量双上限 + 最低剩余空间”，不推荐完整临时现场永久累积。2026-10-20 的本批任务已发生磁盘不足导致归档中断；任务数不能代表占用，多个语言的准备层、逐帧图片、透明视频及 ZIP 都会放大空间。

本轮实现配置和只读预览，尚未实现自动压缩、删除交付包或后台清理。超限是需要处理的信号，不是可以突破知识、复用、账本和正在运行任务保护的授权。不会因超限降低画质、改配音、减少审核或取消知识证据。

## 当前可调配置

默认值在 `config/storage-policy.json`；个人设置写 `config/storage-policy.local.json`，不会带入公开部署包。

| 区域 | 建议数量上限 | 容量上限 | 计数方式 |
| --- | ---: | ---: | --- |
| runs | 20 | 8 GiB | 每个目标语言的独立 run，含未完成任务 |
| outputs | 100 | 20 GiB | 索引中实际存在的独立交付/复用包；所有文件都计入容量 |
| media | 50 | 5 GiB | 源哈希目录；容量包含源解析快照 |

最低剩余空间默认 5 GiB。这些是可调的预警值，并不是本机一定可以容纳的配额；磁盘小的用户应降低容量或迁移素材盘。`0` 表示关闭对应上限。永久知识与未结清账本不参与数量淘汰。

```powershell
.\bin\va.ps1 storage-policy show
.\bin\va.ps1 storage-policy set --area runs --max-count 10 --max-gib 4
.\bin\va.ps1 storage-policy set --area outputs --max-count 60 --max-gib 12
.\bin\va.ps1 storage-policy set --area media --max-count 30 --max-gib 3
.\bin\va.ps1 storage-policy set --minimum-free-gib 3
.\bin\va.ps1 storage-plan
```

跨平台使用 `python bin/va.py` 加相同参数。可在个人 JSON 设置 `pinned_runs`、`pinned_sources` 数组，固定保留指定任务或源。预览列出运行锁、未终结模型任务、未知账单、缺少质量结果等阻塞；即使无阻塞，仍需确认对话已结束并通过已有 `run-preserve → run-delete` 门禁。预览不会计算可安全释放的承诺值。

## 后续精简的内容边界

| 内容 | 建议生命周期 | 保留/删除条件 |
| --- | --- | --- |
| 正在制作的 run | 完整保留 | 不按年龄、数量猜测任务完成 |
| 已结案 run 的草稿、全量抽帧、失效渲染 | 短期调试 | 先检查实际依赖和独立归档；过门禁后清理现场 |
| 最终成片、定稿、语言音轨、排版与复用依赖 | 较长期交付包 | 保留原字节、哈希及恢复能力，不重编码压缩替代 |
| 同源解析、无字底片、背景轨 | 按源共享 | 新语言仍使用；任何有效包或任务引用时禁止删除 |
| ZIP、预览下载副本 | 短期/按需生成 | 先确认不是唯一成片或唯一未通过候选 |
| 知识规则、精选正反例和实际证据 | 长期 | 去重/提纯需保留来源和可验证依赖；不按 run 数淘汰 |
| 未结清请求与账本 | 结清前保护 | 未获计费回执不改成零、不因空间不足删除 |

最终交付和复用包需要较大的保存上限，工作现场可以较小。当前包已按依赖收集必要素材，但同源跨语言仍复制部分准备资产。下一阶段可以引入带引用计数的不可变共享素材库，让一份源片/底片服务多个语言包；必须先具备事务发布、并发控制、引用验证、垃圾回收与迁移恢复测试。

**能力与存储的边界**：删除可重建草稿可以不改变已交付视频的字节和质量；删除最后一份底片/源解析，会降低以后同源翻译速度；删除最后一份成片，会失去历史下载。希望这些用途完全保留时，容量达到上限应扩容或迁移到其他磁盘/对象存储，而不是自动删除。任何有限空间都不能无限保留全部历史。

## 发布前迭代目标

1. 完成依赖闭包核验后的工作现场精简，避免保全时再次全量复制而占满盘。
2. 下载包统一登记生命周期，防止散落 ZIP、预览副本绕过上限。
3. 新任务按源时长、分辨率、语言数预估峰值临时空间；不足时先整理或迁移，不能开始付费后才发现归档失败。
4. 自动清理必须支持预览指纹、固定保留、未结清保护、原子执行和中断恢复。输出过期需明确选择影响，不能默认破坏复用。
5. Windows/Linux 的依赖、字体和模型缓存固定版本，验证独立部署；当前配置/CLI 可迁移不等于云端已验收。
