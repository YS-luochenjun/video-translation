# 真实需求 Benchmark

在现有工作台“效率”页查看；不另建跑片服务，不重做旧需求，不触发模型、平台上传或清理。指标用于逐步了解稳定版本下的首轮表现，不能由历史聊天总时长推断正常制作速度。

## 使用

1. 用 doctor 验证的 Python 启动 `workbench/start.py --background`，打开 <http://127.0.0.1:8768/#efficiency>。也可先运行 `python bin/va.py ledger sync` 建立基线。首次成功采集把现有全部需求列为排除基线，并永久保存启用时间；重启不重置。
2. 后续照常接收真实需求；Agent在登记后及整轮交付/停止前各运行一次 `ledger sync`，无需用户提醒或一直打开工作台。Agent 按[台账流程](../agent/workflows/ledger-tracking.md)执行 `claim`，阶段变化 `stage`，确实暂停整条需求时 `block`，恢复 `resume`，停止负责 `release`。规格须使用真实绑定、owner/session、稳定 operation_id；不需要用户逐条录时间。脚本自身计时自动导入。一个语言等待而其他语言仍制作时，不登记整条需求阻塞。
3. 在源清单填写真实 `content_features`；analyze 的 `analysis/media.json` 提供时长。多语种重复的源观察只计一次，有冲突或缺失则保留未知，不能为填满统计补猜。
4. 照常完成全部原片、全部目标语言、实际审核和平台回传。工作台每15秒读本地证据；关闭浏览器仍采集，关闭服务后可用 `python bin/va.py ledger sync` 补采实际落盘记录。查看 JSON：`python bin/va.py ledger benchmark`。该查询不启用采集、不制作、不查询供应商。

当前启用记录、排除基线和样本快照保存在 `state/ledger/ledger.sqlite3`，不是临时缓存；随 `ledger backup` 一起备份。首次启用时尚未登记但实际收件/开工早于基线的需求也排除。基线需求后续返工不会混成新首轮。不要删除数据库来“归零”数据。离线期间缺失的 Agent 事件无法凭文件时间还原，显示未分类。

## 时间口径

| 指标 | 起止与证据 |
| --- | --- |
| 收件至首轮完整输出 | 真实 received_at 至相同源哈希、目标语和内容版本范围的首次完整输出，包含排队、制作、审核和等待；不是每种语言各花这么久 |
| 首轮制作跨度 | 首个真实 claim/阶段/执行器事件至上述完整输出；不是纯工作时长，跨度内仍可能等待 |
| 首轮执行器占用 | 已结束的最外层脚本区间，并行重叠合并；包含同步请求等待，不等于模型计算或 Agent 总工时 |
| 明确等待 | 真实 block 至 resume；重复更新原因不重复累加；未解除显示仍在等待。可与并行执行器占用重叠，不把两列直接相加 |
| 返工 | 首次全部完整输出之后的真实脚本区间/明确等待；跨边界区间拆开，内部首轮试验和有界修正仍属于首轮 |
| 未分类 | 收件至输出（未完成时至观察时点），减去执行器与明确等待的区间并集；可能含推理、审核、调度和未记录等待，不能称为空闲或工作 |

未记录等待不填成0，未结束计时不估算为已完成。没有首轮完整输出的需求保留进行中，不用部分语言或候选文件当完成。首轮成片哈希、各语言首版质量记录独立冻结，后续返工、包到期或质量提升不改写首轮结果。范围改变后停止原样本跟踪，未完整的旧范围不进入完整样本统计，不把新增语言的耗时混入原首轮。

## 分组与判断

按采集口径版本、采样时 Git 提交、最长原片时长档（默认≤30秒、30–60秒、>60秒）、已观察复杂特征、原片数、去重语种数及语言任务数分组。复杂特征是描述性分组：运动/遮挡/多角色优先，其次艺术字/表面文字，其余已观察特征另组；缺特征为未知。这不改变制作选路、预算或质量标准。

同组展示样本量和中位数；默认少于6条标为探索，至少20条才给最近秩P90。上方自然日趋势与 benchmark 分开，benchmark保留筛选需求的全部前瞻样本。缺失分组不能支持精确复杂度结论；混合代码版本不合并。样本不足不发布耗时承诺，也不自动改现有未校准ETA。

首轮质量通过、完整输出、平台回执和用户验收分别记录。费用展示当前请求账本中已知实付及未知笔数，包含返工；没有时点账单不冒充首轮费用。平台回执仅作回查依据，不从有回执推断全部已入库或 YouTube 成功。

## 交付索引兼容

工作台优先 `state/delivery-index.json`，仅在它不存在时回退 `outputs/index.json`。新版精简包在 `outputs/.packages/`，保留 final.mp4 和必要审核JSON；不能当作完整现场恢复包。仅放行该固定隐藏子目录，仍拒绝其他隐藏路径、越界链接和非媒体下载。manifest与索引/视频哈希匹配后才计输出。expired条目只显示历史与到期状态，不能当可播放成片，也不重新生成制作ETA；已有质量异议继续保留；已采集的首轮快照独立保留。新版索引损坏时报告问题，不借旧索引复活过期内容。
