# 用新视频验证项目

用未处理过的源视频检验首次解析与方法检索；用同源第二语言检验复用边界。此前的清理记录不代替当前目录检查。

## 首次制作

提供本地视频和目标语言，由 AI 按 [工作流](../agent/contracts/workflow.md) 完成实例、定稿、路线、候选、实际审核及交付。源片没有历史同源记录时，`source_references` 不应返回其他源的参考；通用 `knowledge` 仍可按内容特征命中。

`analyze` 会保存新快照，因此解析后的 `source_snapshots` 可以包含当前任务本身。核对其源哈希、参数和来源，不能把新记录误报为历史命中。

先通过共享底片，再完成一个代表语言，最后扩展批次。原字幕、音乐、音效、遮挡、转场和目标语言同步分别审查。具体场景没有证据时保留 pending。

## 复用测试

同源第二语言可以复用核验过的源解析和符合当前资格的准备资产；重新建立译稿、配音、时间轴、文字层和评审。修改定稿或声音参数后不能沿用旧配音。缓存命中与质量通过分别记录。

## 报告与清理

记录实际结果、失败区间、修改变量、费用与证明范围。真实成片、技术回归、同一 Agent 自审和用户验收分开；没有同条件计时不承诺固定速度提升。

成功由 `deliver` 归档；已有候选但失败用 `reflect`，未形成候选时用 `close-failure` 保存有证据的失败观察。按 [存储合同](../agent/contracts/storage.md) 保全后清理；知识和未结算账本继续留存。模拟环境的准备见 [干净导出](project-layout.md)。
