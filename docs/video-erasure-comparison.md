# 有限三模型去字测试

2026-10-26项目用户明确授权：先解除Seedance Mini的测试限制，用同一复杂背景文字视频比较Wan 2.7、Wan 2.6 Flash和Seedance Mini的去字效果及实际credits，再决定默认。

生产默认继续由config/model-routing.json控制。测试使用model-task既有任务账本入口；不全局删除Seedance≥2禁用规则，不开放Seedance Fast。显式video_erasure_comparison授权绑定用户原话/事件、原视频哈希、独立测试run、原请求预算、相同5秒片段哈希、720p、同一去字提示词、固定估算与总额度。每模型一笔；失败或未知任务保留费用与尝试，先查原taskId，不能靠换packet重复提交。

源文字由Codex按codex-packet实际看图并登记codex-result。范围仅去字测试，不冒充新的目标语交付或音频验收。先冻结评分协议和保护对象；模型结果保持原文件，先检查时长/帧率/完整解码，再匿名冻结视觉候选并评残字、纹理、保护对象和时间轴。相同Agent的流程遮蔽须如实署名，不能称独立盲评。

实际扣费取供应商任务回执，非终态或缺计费字段继续保守占位；余额差不能独立归因某笔任务。接口成功、技术结果、内容效果、用户认可分开。参考生成模型即使去字干净，重写人物、表情或动作也不能当作保真编辑获胜。单源一轮结果只支持该类条件的候选选择，不能证明全素材通用排序。

结果、原视频、共同片段、授权、packet、任务ID、原始回执、匿名映射、观察及实际输出哈希独立保全；不能删除其它请求的未知费用。测试结束后执行maintain --close，若因没有完整翻译交付或历史账本未知项不能关闭，保留实验现场并报告原因。推广仍按知识合同保留来源和证据，不能仅凭价格修改默认。
