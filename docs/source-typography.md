# 视频源文字样式：先记录，再重建与审核

来源：项目拥有者要求改善视频字体效果，并参考单图片翻译的样式分析与分层设计；不迁移逐图像素修补、专用重画脚本或逐帧生图。目标是保留可观察的风格与信息层级，允许有依据的语言适配，不承诺恢复原字体文件或任意艺术字完全一致。

后续默认按[源视觉语言制作政策](../knowledge/rules/source-led-visual-localization-v1.md)执行。它由056日语V3的用户视觉认可及明确后续要求启用；案例的日语、字体、坐标和质量结论保持限定，不能复制为其他视频参数。

## 完整画面翻译的目标

按[自然去字与有界提交合同](../knowledge/rules/content-aware-text-restoration-v6.md)，译文替换源画面内的原文，并重建其设计效果。例如用户认可的Test Now→今すぐ試そう：红色字面、白蓝黄多层描边、相近视觉分量和原位构图，字外背景保持自然。普通底部字幕不能代替标题、CTA、场景文案的逐处翻译。原片字幕同样按其原风格和实际目标配音时间重建。

风格重建是制作目标；尽力到界后的字体差异或普通局部修复痕迹如实披露，仍提交全部最佳完整译片，不增加“必须完美”的发布门槛。截图认可仅限定其可见静态效果，不能推断整片声音或运动验收。

### 标题、花字与艺术字优先还原

2026-11-26 用户反馈驳回需求涉及标题模糊及字体不一致，并明确要求后续关注标题清晰度、花字和艺术字还原。APC-20261126-011 的返工正文另明确指出约两秒处漏帧及标题花字不清晰。每条原片优先识别主标题、强调文案及艺术字，保留原尺寸样式依据，选择与原字视觉风格相近且目标语字形完整的真实字体；复杂造型使用适配目标语的清晰艺术字资产，保证实际呈现尺寸的清晰度，避免低分辨率素材被放大。

片头吸引注意的文案、全片主标题、片尾CTA及需要翻译的结束卡文案属于高视觉优先级。先在清单中识别这些实例，再按实际原片选择制作方式：

- 原片采用花字、特殊字形、多层描边、渐变、立体阴影等复杂效果，或普通排版难以达到原片的清晰度、鲜亮程度及视觉分量时，首选宿主 ImageGen 制作局部透明目标语艺术字资产。可在首次制作直接选用，无需先交一版普通字体。已有标题暗淡、杂乱、模糊或字体风格明显不符的反馈时，优先试验此路线。
- 原片为常规字体、纯色或可准确复现的简单描边时，继续采用真实字体及现有确定性排版。口播字幕、普通UI和正文仍按各自实际样式及运动选择路线。画面其他复杂艺术字可按同一视觉条件采用该方法。
- 先用原帧、实际样式观察及目标语定稿构建 `codex-packet`，按[艺术字提示词模板](../agent/templates/style-artwork-prompts.json)生成文字资产，再用 `codex-result` 登记实际产物。逐字核对字形、拼写、断行、RTL连写及透明边缘，在目标呈现尺寸检查细节。使用现有 `style-layer`、surface 或 Remotion 合成到已审核的无字底片，按原片重建位置、大小、渐显、弹出等运动。人物、产品、背景、箭头及需保留品牌标志沿用真实原片。复杂轨迹、遮挡与去字问题继续按相应合同处理。

代表语言先验证最难的高优先级实例，并对片头、主标题及片尾分别检查实际编码样片，再按批次合同扩展其他语种。各语种分别对照原片及最终编码视频，记录文字清晰度、字形风格、字重、大小、色彩鲜亮程度、描边层次、阴影、构图及运动；检查入场、正常显示、出场及前后相邻原生帧，修正漏帧、原字残留和可见模糊。明确返工异议按对应需求逐项验证修复结果，沿用现有质量门禁、预算及有界返工。

**生成量与成本。** 优先复用同源无字底片、原样式观察及同语定稿对应的已验证资产；同一静态字形或简单运动只生成一次并用于覆盖时段。通常每个需要艺术字的语种规划1至2次生成请求。同语种的多个独立艺术字可在分区清晰、分辨率充足且能分别准确裁切核验时合并生成。出现错字、透明边缘问题或不清晰时按必要性有界重试，或采用已实际核验的字体与字层方案。按实际调用次数、有效资产数、重试和可取得的宿主用量记录成本；宿主 ImageGen 用量与 KIE credits 分别记录。用量或单价未知时明确保留未知。

本次优先级调整依据用户对 APC-20261126-008、APC-20261126-011 片头标题及片尾的反馈和实际繁中修复对照。可见对照中，新艺术字的字重、清晰度、层叠描边与颜色更接近原片。该观察支持同类复杂标题优先试验，其他语言、运动和整片效果需要各自审核。

## 先保留原片依据

新 `init/ingest` 请求带 `source_style_contract_version=1`。Agent在擦字和选路前查看实际原帧，按相同风格分组全部待译文字；去除发布者标记与保留原字项另走原合同。参考[样式模板](../agent/templates/source-style-capture.json)，由Agent填写原文清单、样式事实及疑点，不向用户追加表单或询问字体ID。

记录字形类别/粗细/斜体、填充、描边层次、阴影/材质/弧度、行宽与换行、位置与容器关系；运动另分static/rigid/complex，并说明实际观察。`font_class`是视觉类别，不能把推测的字体文件名当成事实。坐标与线宽按原尺寸记录，语言变化需重新适配。

## 剪映字体的参考边界

根据设计师对当前素材的来源说明，原片字体多数来自剪映（CapCut）字体库。后续选字体时，先将剪映中与原片字形、字重、宽窄、圆角/棱角、倾斜、描边承载能力和视觉重量接近的字体作为优先候选，并在样式记录中注明候选来源。这里是候选来源和比对方向，不是要求所有译片强行使用剪映字体。

只有实际原帧比对和目标语字形测试支持时才采用某个候选。若剪映候选缺少目标语字形、无法承载原有描边/阴影、破坏RTL连写、造成越界或明显改变视觉重量，应记录淘汰原因，再选择其他可用字体或艺术字路线。不能因为“剪映字体”这一来源说明就跳过原片观察，也不能随意换成系统默认字体；无法确认具体字体时，记录“剪映候选/近似方案”及具体依据，不把推测的字体名称写成事实。

```sh
python bin/va.py style-capture RUN inputs/source-styles.json --apply
python bin/va.py style-reuse TARGET --from-run SOURCE
```

capture从当前run的**原始视频**提取每组1至3个必要时刻，去重相同时间；不接受任意底片冒充源帧。快照位于run的analysis/source-styles内容寻址目录，包含源哈希、原文/时间/几何、实际帧及设计观察。重跑复用未变字节，新观察生成新目录；不会重写旧快照。其存在不证明Agent观察正确或连续运动通过。

`--apply`只绑定inventory.source_style_snapshot及实例source_style_id。目标文案、字体、布局、route与审核仍分别建立。style-reuse仅复制精确同源、同实例/几何的原观察与帧，清除目标style_treatment，绝不复制语言认可或直接调用付费模型。源run不存在时先按交付恢复合同恢复包，不根据路径/哈希假装资产还在。

## 每实例选择目标路线

inventory实例填写 `style_treatment`：route、reason、adaptations；typeset另写font_choice_reason。adaptations为“改变的方面→具体理由”，没有变化填空对象。颜色、斜体、字重、分行、描边、对齐变化必须说明；承认变化不使质量自动通过。宽高、材质、视觉分量、运动和保护对象仍须实际看成片。

原文擦除几何保留在实例bbox/source_interval，不为移动译文改写原观察。需要调整静态译字位置时用display.bbox并记录layout适配；display.line_height控制显式多行间距。固定目标框不能暗中替代动态轨迹。

| 观察与目标 | route与执行 | 切换及限制 |
| --- | --- | --- |
| 常规字或可用字体/描边/阴影表达的造型 | typeset：真实font_asset，display填写字体效果与明确换行，走已审底片或erase_then_overlay | 字形缺失/粗斜体不实/最小可读字号放不下时停止，不隐式换字体、不无限缩小；先等义断行或换合适字体 |
| 少量复杂艺术标题、CTA | imagegen_asset：按ImageGen优先政策制作局部目标字/装饰资产，逐字核对，再绑定现有surface_typography透明视频层 | 不自动生图，不重画整帧人物；复合容器资产如实标注，保留原字清底与保护对象审核 |
| 跟随移动、表面或遮挡的字层 | tracked_layer：现有外部surface字层及真实轨迹/遮挡来源 | 路线名称不能证明跟踪完成，每个覆盖镜头都须有实际字层与来源回执；内置Remotion仅支持其原有简单动效 |
| 连续变形/复杂遮挡确需视频编辑 | wan_reference：实际同镜头参考图与Wan替换文字任务 | 原片控制运动；去字参考与译字参考用途分开，erase-only不能宣称已按参考生成译字，仍实际审字形与连续帧 |

复杂度与运动是两个维度：静止艺术字可只制作一次资产；普通字也可能有复杂遮挡。不逐帧制作图片，不要求所有字体都试失败后才用ImageGen，不预设必须付费。全部文字仍翻译，额外视觉设计优先用于显眼标题/CTA/场景艺术字。沿用原预算与两轮有界返工，不重开费用池。

### 绑定真实字体，而不是默认Arial

原有font-bind --family可继续用于已登记字体家族。新增明确字体文件入口，支持实际存在的装饰/粗斜体或TTC字面；不自动下载、安装、购买或合成假斜体。

```sh
python bin/va.py font-bind RUN --font-path "/available/font/BoldItalic.ttf" --text "Final target copy"
# TTC可加 --face-index 具体字面索引；返回的path/sha256填到display.font_asset。
```

目标例：display.font_asset绑定真实粗斜体，bold=true、italic=true、color=#000000、outline=5、outline_color=#FFFFFF、font_size与min_font_size按区域填写，译文用显式换行保留两行构图。不同语言各自核验字形；原字体不含中文时，选择视觉类别合适的中文字体并说明适配。min_font_size不能作为“足够可读”的自动证明。

普通字层的FFmpeg合成实际加载绑定字面，按同一字面测量，支持原有多层描边、阴影、倾斜与轨迹；指定斜体却提供直立字面会报错。复杂弧形/材质/透视不因这些字段存在就称已实现，应选艺术素材/专用表面字层或有据披露降级。

## 渲染时的工程核验

绑定字面在FFmpeg/libass中使用按字体哈希生成的局部唯一家族名，保留物理字重和字形；原始绑定资产不改名、不覆盖。这样同一家族的Regular/Bold或不同粗体字重不会只凭bold布尔值相互替代。局部导出字体及来源哈希保存在渲染回执中，缓存被改动时报错。

静态排字测量计入最外层描边、阴影和实际字形边界；容器放不下时先等义断行、调整有据的布局或字面，不能低于显式最小可读字号。测量通过仍须查看最终编码短语及相邻实例，不能证明透视、复杂变形或所有字体的视觉一致。

清底对照除区间首/中/末帧外，追加前后各一个实际原生帧，捕捉擦除范围外的单帧残字；source_ghost_interval另行覆盖。每区间最多5帧，未变输入复用，不逐帧生图，也不自动延长修复区间或判通过。工程回归与适用边界见[原生渲染与取证](../knowledge/rules/native-render-evidence-guards-v1.md)。

## 计划、样片与交付

### 批量生成字层

使用 `agent/templates/style-layer.json`，正文的 `display.timed_fragments` 来自已审实际配音对齐，`font_asset` 由font-bind取得；`artwork`只引用少量已实际生成、逐字检查的透明PNG。目标框在display.bbox，源擦字框不变。无需每次编写素材专用PIL字层或逐帧管线。

艺术字和去字参考可从[提示词模板](../agent/templates/style-artwork-prompts.json)填入实际原帧观察与目标定稿，二者用途分开。只继承结构与保护约束，不照搬056日语文本或造型。正式plan的surface路线仍要求已核验的prepared底片；字层生成不承担去字，也不批准底片。

```sh
python bin/va.py style-layer RUN inputs/style-layer.json --apply
```

命令复用现有真实字体排版，批量生成所选镜头的透明surface字层；静态或有据的简单pop适配可一次渲染，复杂轨迹/遮挡继续走既有专用surface/Remotion路线。绑定源、定稿、短语、字面、输入图及原生帧时轴；未变输入复用，不擅自去字或发模型请求。`--apply`绑定实例与镜头surface，保留之前inventory；随后重建计划或fast-register并审核。要求透明素材、完整定稿及不覆盖显式保护对象；不提供视觉pass，也不将模型参考图自动变成正确的译文。

普通plan与fast-register都冻结source_style_contract，重新核验源快照、帧、字体和目标选择；任一被改动都须重新计划。实际文件随独立交付包保存，不只留下旧run路径。旧请求没有新版本标记且未主动绑定快照时保留原合同与历史判断，不重做已交付视频。

先完成一个代表语言的完整样片，再按既有batch-approve扩展。新审核模板source_style_review逐实例检查lettering/layout/motion/protected_content，附实际观察和当前视频capture里的图片。仅凭原帧、音频、旧版本图片或勾选“通过”不能放行；缺证据/明显失败阻断quality通过。轻微差异按原质量标准记minor，记录适配不等于风格一致，完整输出与质量通过继续分开。

本功能没有自动识别并复原任意字体，没有新增跟踪模型，也不会自动调用ImageGen或Wan。保存一次源设计、复用源观察和现有字层机制是为了控制重复分析与生成次数；实际节省时间/改善程度须用具体视频验证，不能由单图认可推断。
