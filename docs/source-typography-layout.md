# 目标语排版

总入口见 [source-typography](source-typography.md)。

### 目标语排版由 Codex 决定

依据 2026-11-26 用户对换行及返工需求（如 APC-20261126-098）的反馈：**原文的行数和断点是观察依据，不是译文模板。** Codex 先看原片、目标语定稿、实际字形及文字周围的空间，再为每种语言确定分行、字号、对齐与落位。等义短译文能在原文字区保持视觉分量就用一行：英文 `how old` / `are you` 两行，中文 `你多大` 应一行，不拆成 `你多` / `大`。较长译文允许增加行数，在目标语自然短语边界换行，不拆词、硬留孤字或破坏 RTL 阅读顺序与连写；不要为了塞进一行而把字缩得过小。

**适用于每一个目标语种，不限于中英，也不限于标题。** 同一原片可复用源样式观察，不复用其他语言的断点、字号或验收。Codex 按实际译文重点检查：

- **长词或译后明显变长**：例如德语、土耳其语。先试自然短语换行和区域适配；不在词中硬断，不为与其他语种统一行数牺牲可读性。
- **附标和较高字形**：例如越南语。用实际字体检查音调符号、上下伸展、行距和进出场边界；不能出现标记被裁切、描边吞字或上下行碰撞。
- **依靠分词而非空格换行**：例如泰语。按真实词组和标点定断点，不按字符数硬切，也不往定稿强塞空格。候选工具未支持该断点时，在场景文字定稿中指定视觉换行；口播字幕从原有对齐片段指定，不改配音文案和时轴。
- **从右向左的混排**：例如阿语。按实际成片核对方向、连写、标点及数字或拉丁品牌名的位置，不反转字符来模拟 RTL。

这些是检查例子，不是按语言固定的排版模板。若空间不足，可采用简洁的等义说法，但不能丢失数字、否定、卖点或 CTA；口播字幕仍与实际配音共用定稿。代表语言通过不代表其他语言通过，各语种的标题、正文、UI、字幕与片尾 CTA 均按实例核对。

以真实字面的可见宽高和描边、阴影占位判断字号，不照抄源字号数值。保留主标题、正文与 CTA 的视觉层级、原布局锚点和运动；原区域内可按目标语调整文字框和对齐，不移到无关位置、不盖人物、产品或其他受保护元素。相同作用、相同风格的标题或字幕避免无依据的大小和对齐跳变。先调整短语分行、适配字体或区域，再考虑缩小；Codex 已定的字号可将 `font_size` 与 `min_font_size` 设为同值，放不下就回到排版判断。

排字用 `display.layout_lines` 指定选定的分行，`display.bbox`、`align`、`font_size` 和 `min_font_size` 落实大小与位置；口播字幕按实际目标配音定时短语在 `display.timed_fragments` 内安排分行，不对所有片段套一个整句分行。艺术字资产按同一排版决定向 ImageGen 明确文字和分行，合成时定位，不由参考图的原行数决定。分行或落位变化用 `style_treatment.adaptations` 记录依据，保留原文的擦除框和时段。逐语在实际编码成片中检查断点、清晰度、视觉分量、位置和遮挡，不以候选测量代替审片。
