# ImageGen 图片优先与当前视频模型组合

宿主 ImageGen 可满足自然图片创作、背景去字、纹理修复及艺术字需求时优先用。说明允许改变的区域和应保留的主体、结构及透明通道。按 codex-packet 和 codex-result 绑定实际输入与产物。抽帧、遮罩、精确字层、时轴及编码保留现有确定性工具。

| 观察 | 选路 |
| --- | --- |
| 静态底面或独立图片修复 | 先考虑宿主 ImageGen，之后用真实字体或艺术字层合成。 |
| 持续运动或纹理需生成，且同镜头图可准确表达目标外观 | 优先评估同镜头 ImageGen 参考和原视频组合。按[模型合同](../../agent/contracts/model-routing.md)绑定真实源片段和参考。 |
| 原视频和提示已足够、参考图改变主体或几何，或已有局部结果足够 | 按实际风险选择单独编辑或合格同源局部，记录切换理由。 |

清底参考只表达背景和删除区域。目标文字参考先核对拼写、结构和字形，再明确参考只约束的部分。每镜头验证画面身份、构图与遮挡。参考文件实际上传和供应商请求字段以[现行接口合同](../../agent/integrations/kie.md)为准。提交前核对 `shot.reference_image` 的真实文件与哈希、请求包内资产及实际请求字段，提交后绑定 taskId 和结果哈希。原视频提供真实运动和时间轴。

原尺寸比较连续帧、边界、主体身份、正常播放与闪烁。只采用有效的同源对应区域。模型或图像成功后仍需审查连续底片、叠字和实际成片。组合为按内容评估的优先路线，按原预算和返工边界停止。

[MOG005](../cases/mog005-en-imagegen-wan-local-adoption-v1.md) 和 [APC024](../cases/apc024-ja-imagegen-wan-upper-trial-v1.md) 是旧模型的局部实作，历史模型身份和控制变量限制随案例保存。修订依据为 evidence:previous、evidence:routing、evidence:interface。
