# 文字、界面与前景：按对象分层，保留风格并检查实际编码帧

按内容选读：animated_text、artistic_typography、filmed_phone_ui、foreground_occlusion、surface_typography 任一特征命中。静态界面只执行相关的表面/对象检查，不虚构动画；镜头运动本身不代表文字动画。证据来自多个独立源的改善与失败，不表示各源均已整片验收。

## 三层分别处理

1. **旧字层**：擦除包络覆盖进场、稳定、出场、缩放、抗锯齿、描边、阴影、光晕及拖影。源字擦除区间独立于目标字显示区间。OCR和颜色阈值只提供候选，灰化边缘和半个字需原尺寸核对；不要把案例中的亮度阈值复制为默认。
2. **背景与前景层**：先看无译文底片。恢复纹理时按同一照片、姿态、镜像方向和实际擦入位置配准参考；文字光晕内的合成边界可能带回色污染，应局部验证边界而非无限扩大矩形。图标、箭头、手部、骷髅分别作为前景，保留完整轮廓和半透明入场；相同颜色不等于同一对象。供体里重画的图标须先处理，避免源图标叠回后重复；从旧译文成片截前景可能带回旧字。
3. **目标字层**：测量目标语言的字形、行宽与换行，重建入场/回弹/稳定/退场、颜色、透明度及遮挡顺序。口播字幕按实际目标配音对齐；独立标题/UI按其画面语义。表情或箭头与短语有关时重查关联时机，不能只把所有效果替换为固定颜色字幕。省略图标或近似光效须记录偏差，不能因正文译对就称动画保真。

## 仅在对应场景执行

- **艺术字**：分别观察字形、填充纹理、描边和有方向的立体偏移，再处理运动。先保证目标字形可读；仅改成相同颜色不能复现纹理，同心描边不能代替偏移阴影。逐实例核对纹理尺度、轮廓比例、边界与遮挡。已有照片广告对照证明了该例的改善；新源能否重建纹理仍需试制，原字体恢复未获证明。
- **手机界面或相交对象**：同名标题在主界面、缩略图及字幕胶囊中分别绑定对象与层级。前景保护不能因肤色/亮度相同而吸收缩略照片或背景；译字留出图标间距后，还要单独检查无字表面。若填补把白色图标拖入背景，应先将图标排除出填补供体，再按原轮廓与透明度复原，检查运动中的遮挡与接缝。不要只继续增大文字间距或擦除矩形。

- **显隐转场**：分别观察对象的几何位置/字面高度与可见边界。对象不动而可见区收缩时，保持字形几何并匹配源遮罩/透明度；确认对象本身缩放才同步变换字层，两者同时发生则分别建模。用跨区域源像素和连续边界帧核对，单条颜色扫描可能把照片误认成光环。检查提前消失、重新闪现和遮罩越界；遮罩形状及变化是否单调按原片确定。静态海报本身不能推出圆形遮罩。

## 时间与实现检查

- 固定帧率用整数帧和明确的左闭右开区间记录边界；变帧率用实际时间戳。模型裁切、变速或插帧后核对帧数、PTS、首尾和原镜头切换。目标语言的字幕时间不复制源语言逐词节奏。
- 实际编码文件才是检查对象。概览图定位后，检查原尺寸问题区域、无字底片、透明字层和连续边界帧。30 fps 每0.2秒取样步长为6帧，只覆盖同一奇偶相位；检查周期性异常需补相位偏移或整段连续帧。OCR为空只表示未识别到，不能证明无残字、无接缝或无闪烁。
- 跨帧复用数组前确认操作是否会原地修改。项目所用 OpenCV 5.0.0 的 seamlessClone 已通过合成探针复现遮罩变化；需要保留遮罩时传副本或逐帧新建。不要把该观测描述成所有版本的 API 承诺。复制控制通过后，仍须复查编码奇偶帧；参数安全不等于视觉合格。

## 失败签名与验证范围

仍露字形/光晕 → 检查完整包络与时间末帧；方块或明暗接缝 → 检查参考姿态和色彩/亮度；冻结/双手/重影 → 检查静态供体及模型重画；表情截边/重复 → 检查轮廓、alpha和供体副本；隔帧回闪 → 检查可变状态与取样相位。每次选可定位的一项原因做有界修正，再查底片和目标成片。

evidence:observations 保留四源状态、正反例及适用范围；evidence:mask_probe 保存运行时探针。可迁移的是分层、时序覆盖和检查程序。隐藏纹理、具体遮罩、字体尺寸、固定前景模板和单次模型成功均不跨源保证；新源须重新验证。纯视觉修复不替代声音审查。

新增检查的来源与边界见 evidence:adoption：艺术字、图标供体和层级有源限定对照，推广的是识别与核验步骤，不是该素材的坐标、模板或成功保证。透明像素隐藏 RGB 的兼容性已完成两个不同于原手部素材的新源验证；适用条件与反例见文末“透明资产导出”。

本次显隐判断补充见 evidence:cta_transition：一个新源的局部反例和修正记录，四语为同源派生。CTA残字、容器归属与前景层级已由现有检查覆盖，仅合并证据。圆心/半径、颜色阈值与单调拟合仍限原素材；局部改善不解除旧成片质量异议。


## 原位置、原失焦层和片尾可见时间

源片已有的标题/功能文案先去旧字，再在同一对象和文字平面复建译文。不能为躲箭头或遮挡，把文案移到原片没有字的位置；需恢复前景轮廓/alpha和原遮挡次序。译文确实放不下时，依据目标语言缩排、换行或有依据改写；仍不可读则记录瑕疵，不能用移位掩盖问题。

分开判断背景失焦与主动遮旧字的模糊。源片在片尾失焦的背景标题/问题、其译文字层应匹配同一层级和变化；前景 CTA/箭头仍按源片保持清晰。先自然去字或有界视频修复，不能用全画面模糊把尚清晰的主体一并盖掉。具体半径、坐标和起始帧只对该源有效。

分别检查源字擦除全包络与目标字显示区间；末尾仍露模糊英语也要登记。CTA保持到源片实际最后可见帧，不按配音结束提前消失。检查最后一帧和进/出场连续帧，并在真实编码结果查亮边、块边、重影及漏出的半字。单张截图不确定对应帧时保留定位不确定性。

evidence:seven_source_review 及 evidence:tail_feedback/evidence:erasure_feedback/evidence:placement_feedback 保存2026-10-27七源整理和三组直接反馈，配套截图为反例/观察。其余四源只在报告所示范围内支持检查程序；70种语言派生不算70次独立验证。修正项通过、样片推广授权或素材入库均不解除旧质量异议、声音限制或未知费用。正文更新不改写既有冻结计划。


## 字体、取帧与承载平面的检查

测量与渲染须绑定同一个真实字体文件、字重及TTC face。字体家族名称或cmap覆盖通过不证明渲染器实际选用了该字形；检查实际编码文字、缺字和替代日志。显式所需字体缺失先修输入；未用到的可选平台字体不阻断任务。导出独立单face资产，并在字体字节、映射、目标语种或运行环境改变时使缓存失效。evidence:font_observation/evidence:font_preview 仅为Mac合成样例和开发者观察，不保证其它宿主、长句或母语排版。

源截图、修复对照和最终检查须使用同一色彩/范围解释。AV1有限范围转JPEG时曾因范围映射产生误导；先核对取帧设置和实际源图，不把取帧偏差判断为模型调色。AAC可能长于视频，片尾图按真实视频流末帧取，核验文件确实生成；容器总时长不保证末帧存在。具体旧缺陷见 evidence:capture_review。

原文字位于转动纸张等平面时，擦字区与目标字共同跟随源平面，背景卷边、前景水印和退场独立处理。给定的仿射轨迹不证明自动跟踪、非刚性形变或遮挡修复；Remotion的固定屏幕区域能力仍按其合同使用。全局中位数供体的页边接缝、静态图传播的双影/冻结、宽CTA掩模损伤纸张轮廓，都须在无字底片及连续边界帧检查。局部改好一项不放行其它区域。

evidence:remaining_review 保存本轮十个源的限定观察与124组使用观察的审查范围。SHE053的源/旧/改后CTA截图仅支持样式改进，改后仍有背景锐度和补丁问题；不把红黄蓝或特定字重作为全局偏好。旧LaMa/OCR、模型排行榜和低预算变速试验仅历史，不构成新调用方案。新方法选路仍服从当前Codex/Wan、预算和正常播放质量合同。


## 透明资产导出：仅清理完全透明 RGB，并验证下游

触发：导出/复用带透明区域的前景或字层，或下游丢弃alpha、缩放/旋转、转换格式。先明确straight/premultiplied、位深、色彩及真实消费方式。alpha隐藏不代表RGB已删除；Pillow直接转RGB或OpenCV按彩色读取，已在实际前景中露出原片英语。会忽略alpha的消费者应先在明确底色上正确合成，不能把清零后的黑底RGB当作透明结果。

对明确的8位straight-alpha RGBA派生副本，可只将`alpha == 0`位置的RGB清零；alpha及所有`alpha > 0`像素的RGBA保持原值。不能把低alpha阈值、去背景、抠图轮廓修正或可见文字擦除混入这一步。保持原始绑定资产不变，新文件单独登记哈希和来源；辅助实现为video_localizer.alpha_assets.sanitize，默认不裁切，也未强制接入现有制作链。

清理优先作为导出末步。还需空间滤波时，先采用正确预乘颜色与alpha的缩放/旋转，再转换回所需存储格式；核对实际消费链。实测普通OpenCV逐通道插值在清理前后会改变边缘，故不能宣称任意缩放后仍等价。PNG/QTRLE/FFV1的本轮无损往返不外推到有损编码、其它色彩空间、高位深或其它应用。

紧裁切只能依据全部非零alpha的外接框，保留必要留白，并记录原尺寸及裁切原点，合成时恢复原锚点。全透明层明确为空，不能猜锚点。外接框裁切不会修正错误的前景遮罩：本例表情掩模保留的小块背景仍在，不能称为精确抠图。

验证与停止：对比原/清理副本的alpha和可见RGBA，按实际原点还原裁切，至少在深、浅及棋盘格背景检查；继续核对实际变换、编码与消费者。原尺寸及正确预乘路径的结果应一致；出现黑边、颜色/透明度变化、错位或可见像素变化就撤回该操作并检查alpha解释与滤波。不能只查文件更小或RGB不再含文字。

evidence:alpha_compatibility 保存四个实际资产的验证、源/层/帧哈希及边界：两个新源，英文/阿语字层同属一个源，不算独立复验。SHE053表情PNG在alpha被忽略时暴露隐藏原片；Remotion字层含9403/8047个软alpha像素。仅清零alpha=0，原尺寸四背景、实际FFmpeg RGB合成、已测预乘变换和无损往返均保持像素一致。alpha≤8阈值则改变2055/2131个合成像素；逐通道缩放/旋转也是反例。evidence:alpha_preview/evidence:alpha_resampling 是已观察对照。该技术结论不批准任何旧视频、不承诺通用抠图或所有工具兼容。
