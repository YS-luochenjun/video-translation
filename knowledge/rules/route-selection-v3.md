# 按实际内容组合修复路线

适用有必译文字的广告。先按 agent-method-selection-v1 解决规则优先级，再按 content-aware 政策选择主方法；并非命中一个标签就固定整片路线。

1. 静态界面/自然容器：首选经核验的同源底面或 Codex 重建加透明译字；供体光照、姿态、时刻不匹配时换供体或宿主编辑，不用静态补丁冻结动态区域。
2. 艺术字/表面文字/动画/遮挡：组合 source-neutral 与 animated-text 方法，记录字形测量、运动、层级和保护区；持续动态修复确有必要时用已授权 Wan 2.7 短段，核验实际帧映射后局部采用。宿主图片处理只证明图片结果。
3. 移动水印：独立实例和轨迹，组合 watermark 检查，不因译字遮住水印而视为已去除。
4. 先保留可核验画面与声音，复用精确源哈希资产；每个新语种重新建立定稿、字层、配音和时轴。配音走专用音频模型，字幕与最终声音对齐。

首选失败时先定位底面、运动、文字层、音频中的具体失败项；只切换受影响实例，写明一个主要变量和预期验证。当前模型/输入不支持的方案先查能力合同，不能激活已停用模型。局部可见模糊只按 content-aware 的复杂度和主体风险条件使用。

停止条件：满足当前模式；无明确改善依据；达到试验/费用/能力边界。后两种按最终输出合同保留缺陷和音频需求状态，不无限追加算法。主路线与辅助检查、实际使用与仅参考分别记录。

依据：evidence:review。适用条件是选路依据，不保证新素材效果；实际候选仍按当前模式检查。
