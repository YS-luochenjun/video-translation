# 气泡分层排版与动态区域自然去字

适用有原生评论气泡/卡片，或需译文字覆盖移动人物、头发、纹理及遮挡的素材。用户明确要求后续类似素材优先沿用本次有效方向，同时说明后续不一定使用 Wan。这是处理方向的授权，不是任意模型、无限预算或未见成片的验收。

## 优先方向

1. 气泡保留原轮廓、头像和尾角；只重建污染的原容器内部。说明、姓名、正文分层，通常共用左边界；姓名完整，正文更突出。逐语言测量字形，记录安全区、最小字号和人工确认的换行。装不下时改写或重新分配空间，不无限缩字。原设计明确需要居中时仍按实际设计判断。
2. 简单静态底面先自然重建；文字跨移动主体时优先评估保留运动的自然去字。用实际困难片段验证，再处理其他出现区间。不能把“大块模糊”当作动态难度的证明。
3. 模型是可替换执行器。按当前可用且获准的路由、输入长度、主体保真、时间一致性、成本和真实结果选择；Wan 2.7 仅是本案例验证过的实现，不是后续必用型号。模型切换仍遵守实际能力合同和账本，不因本经验自动放开未批准模型。
4. 去字与译字分离；先修复共用无字底片，再叠加各语种准确字层。经检查的底片可跨语种共享，字体、整形、长度和各语种成片仍分别检查。

## 可复用代码

- `src/video_localizer/container_text.py` / `bin/render_container_text.py`：透明字层、分块对齐、字形测量、最小字号、容器及头像保护、跨块碰撞检查。输入示例为 `agent/templates/container-text.json`。泰文等必须启用塑形要求；无塑形能力时转到经过验证的文字渲染器，不能以孤立字形凑合。
- `src/video_localizer/local_repair.py` / `bin/prepare_local_repair.py`：输入模型无关的修复片段规格，生成局部 alpha 和 FFmpeg 合成图。示例为 `agent/templates/local-repair.json`。先从实际媒体读取帧率与帧数；规格不能代替媒体探测或视觉审核。
- 用半开原帧区间记录每次出现；全部目标帧必须且只能由一个片段覆盖。拒绝缺帧、重复覆盖、改变帧率以及拉长/冻结凑时长。模型结果有重叠上下文时显式指定采用窗口。
- mask 使用完整 0–255 灰度透明度，不能直接把视频范围的 16–235 当 alpha；后者会让旧字淡淡透出。先柔化边缘，再将保护区清零。不要把羽化作用在保护区之后。
- 合成范围不等于字的外接框。快速抬头时，过窄的框会在发际线/额头形成横切接缝；根据连续帧适度扩到同一运动表面，保护气泡、头像、标题与游戏图形，再检查边界。扩框不是整个人物任意重画的许可；若主体形态或时序改变，拒绝该候选或有界返工。
- 偶数视频裁切坐标/尺寸避免 YUV420 隐式取整；白色气泡在 RGB/RGBA 合成域处理并检查色阶，避免局部白底变灰。
- 画面帧数限制可能截短混流的音频尾部。先完成画面，再单独复用完整已核验音轨；复用压缩音轨时比较音频包哈希，不能用“有声音”代替完整性检查。

## 验证与边界

检查每次文字出现前、首帧、持续段、末帧和退出后，特别是修复片段接缝、人物快速移动和遮挡。连续帧与正常播放结合看残字、接缝、主体、动作、图形以及声音尾部；成功回执、静态漂亮截图或合成测试都不证明真实视频通过。只重查返工影响范围，但新成片须绑定新哈希。

本案例气泡分层和自然动态去字获得用户“目前效果还可以”的反馈，七个语言版本来自同一源，不能当作七个独立素材复验。存在局部纹理差异、片尾动画近似和原有配音同步限制；这些没有被本次反馈解除。坐标、字号、区间、羽化数值不推广为常数。效果达到当前要求即停止；失败时保留证据，按现行有界返工和最终输出合同处理。
