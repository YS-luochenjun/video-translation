# SHE-20261118-007：手机 UI、免责声明与弹性 CTA

适用原片 `d52157c163dadd4ccdf2250e8184c554ea79894bc5b9e3f1f1fb103bd63109ea`。历史观察来自十七个目标语种，均为同一原片。

- 手机 UI 文字按各原始图标位置和手机几何运动进行原位替换，保留图标、手部和手机主体。历史画面抽样中译文位置可辨，但标签旁有浅灰修复痕迹。完整片尾 Wan 底片曾改变手机、勾号、箭头和彩屑的几何形态，复做应比对这些区域。
- 单独检查底部免责声明及黄色主体、黑白描边的 CTA。CTA 入场高度、弹性超调及稳定位置须结合源动画验证。长译文应检查字重和视觉面积，非拉丁文字应以实际字形和可读性选择字重、斜体适配。
- 只保留原清单明确保留的产品名称，如 FaceTime、TV、App Store。逐实例检查标签、免责声明和 CTA 的原语残留。
- 历史多个语种的整段 ASR 漏掉开头或 CTA，独立首段、末段或对白片段提供了补充边界证据。对充电器、疑问句等存在转写分歧的对白，应按实际目标语言音频核验。

精确语种观察见 evidence:observations，其中包括繁体中文实际字体与 CTA 样式、阿语连写与 RTL、印地语和泰语字形观察以及各语言的音频识别分歧。查阅时只使用相应语种记录，其他语种重新核验。

历史版本品质均为 revise。历史观察由同一制作方基于实际画面抽样与成片 ASR 记录，正常速度播放、直接听审、口型、音乐效果和独立验收仍有证据限制。
