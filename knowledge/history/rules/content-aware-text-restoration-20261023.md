# 按文字底面和运动难度选择去字方式

来源：项目用户于 2026-10-23 要求“在不同的情况下，使用不同的方式进行处理”，复杂视频中的文字可以提高遮罩处理的使用机会，简单背景不必遮罩；并明确认可图一的自然背景效果，指出图二的模糊色块较差。原话见 evidence:feedback。本版替代此前一律要求实际自然修复失败后才使用模糊的规则；认可范围是图片方向，成片仍另行审核。

## 逐实例选路

先看文字下面的真实底面和相邻运动帧，在 inventory 的 reason/evidence 记录判断。同一视频可以同时采用多种方式；镜头复杂不意味着其中每个按钮、卡片和标签都复杂。

| 实际情况 | 优先处理 | 局部可见模糊的使用条件 |
| --- | --- | --- |
| 平色、渐变、稳定卡片、按钮和界面标签 | 同源干净供体、宿主图像编辑或原容器自然重建，再叠透明译文 | 收紧使用；先解决底面和接缝问题，局部传统算法失败不等于自然修复不可行 |
| 界面稳定，但姓名输入、数字、手指或图标在变化 | 共用干净底面，逐时刻保留这些动态内容；文字层独立 | 根据被遮挡的具体小区域判断，不把整张界面统一模糊 |
| 文字跨越移动头发、人物、强纹理或多次遮挡 | 根据真实连续帧判断自然修复的可行性；有明确改进方向时做有界局部试验，必要时用当前授权的 Wan | 相比简单背景更早评估最小局部模糊。连续帧已显示自然重建会明显损坏主体、或当前自然候选效果不佳时，可直接比较一个局部兜底候选，无须逐个穷尽算法或反复付费。保留判断证据与停止理由 |
| 移动、旋转、边缘进出的水印 | 独立建实例并跟踪，检查入场、出场、裁切、转场和片尾标记 | 读取移动水印规范；模型成功或高匹配分数不证明已去净 |

模糊仍是兜底。是否使用由实际背景、遮挡风险和候选观看效果决定；制作时间、连接失败和预算不足不能单独触发。每处记录时间、最小范围、依据、已做试验及保护对象，检查人物、箭头、按钮和手部。技术上选择修复像素的掩模，与图二那样可见的模糊色块分别记录。

## 复用与输出

同源多语言优先复用核验过的解析、自然底片、未变译稿/透明字层和音轨。动态内容按对应源帧取用；若原片仍有水印，回贴原片区域可能把水印带回来，须重新检查。共享底片不继承某语言或整片的质量通过。

困难片段只处理必要时段和区域。模型输出核对帧数、帧率和对应时刻后再局部采用，保护区域继续使用对应源帧；静态参考不能证明连续运动正确。

沿用整请求预算、任务数与返工上限，不因新语言、换 run 或改用兜底而重置。到达边界按最终输出流程交付当前最好完整译片，保留瑕疵、原声/字幕状态。用户认可图片不扩张为整片、全部语言、独立审核或公司验收通过。预览页明确显示当前版本和处理方式，旧版保留历史入口。

本政策来自用户明确选路偏好；具体修复效果仍由实际成片证明。单源字体、坐标、转速和阈值只保存在同源案例，不作为通用默认值。
