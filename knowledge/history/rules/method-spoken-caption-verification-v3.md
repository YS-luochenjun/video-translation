# 多语言口播：共享定稿，对照实际成片处理识别分歧

适用于有人声的本地化视频。合并短句识别分歧、句间停顿和局部返工检查。

1. 区分口播、口播字幕、独立标题/UI及配乐中的演唱采样；采样是否保留由声音职责和用户要求决定，不因检测到人声就全部替换。口播与对应字幕共用目标定稿，独立界面文案保留独立译文。
2. 完成裁切、变速、偏移、回混后，按实际最终声音建立对齐。计划时间、TTS 请求文本和孤立配音都不能替代最终混音；同时检查开头、结尾是否完整，背景音乐与音效是否被误删。
3. 短句 ASR、同音词、文字系统混淆或低置信结果出现分歧时，保留原始转写，结合第二种识别、单独分句证据、波形和可用听审核对。不要静默把识别结果改成请求文本来制造一致，也不因一次误识别立即再次付费配音。仍不确定时保留 pending。
4. 拼接多个语言的音频评审可能把片段边界误判成缺失；保留每段标识、起止时间和独立音轨，以逐段证据复核。逐词时间不可靠时，用经检查的短句级同步，不能伪造词级精度。若下一句在停顿中提前出现，检查 ASR 是否把句前静音分给第一个词；对照实际配音放入混音的位置、语音停顿证据与编码字幕边界，按短语重新定位。能量低不等于静音，气声、弱辅音和配乐需结合语义及可用听审；不要直接套用案例阈值、固定延迟或增益，也不要为追字幕改变背景音乐速度。
5. 对实际成片音轨、显示文字和字幕边界帧共同核验；局部画面返工优先保留已核验同语言声音，再检查音轨身份与同步。音频模型复核、同一 Agent 自审、人耳听审和用户验收分别记录。

证据：evidence:observations。本批整体用户反馈积极，但个别预览仍需视觉修补或听审。本方法不保证母语发音验收、ASR 词级精度、无损分轨或目标语言口型。不同说话人、语速、语言和配乐仍需反证。

停顿例见 evidence:adoption：手势广告中文版本记录了错误词时标、实际发声/放置时间和修正后的编码边界。该例支持增加交叉核验，不证明单一能量阈值适用于其他语言；有歧义继续保留 pending。
