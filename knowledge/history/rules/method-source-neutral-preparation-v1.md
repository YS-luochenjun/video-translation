# 同源多语言：把源解析、中性准备和语言结果分开

这是一条制作与核验方法，适用于同源多语言和局部返工。来自三个独立源素材的开发观察，不保证任意新素材一次制作成功。不同视频不复用旧底片、旧坐标或旧解析结论。

1. 新素材先解析并保存源哈希、源文字/人声观察与镜头信息。同一源文件再次处理时，核验解析快照后复用原始抽帧、音轨和源观察；审核状态和目标语言定稿重新建立。
2. 将不含目标文字和目标人声的底片、几何、背景轨与语言层分别登记。以文件哈希和准备记录证明中性属性；文件名不是证明。
3. 新语言重做译文、配音、字幕时轴、字体适配和实际成片评审。不能把完整中文混音作为日语背景，也不能把中文通过状态移交其他语言。
4. 删除任务前运行保全和预览，确认独立知识证据、源解析快照、所需交付包及已结算账本。

失败签名：旧语言字形或口播泄漏；只剩索引而没有实际素材；局部修字再次调用整段付费模型。完成标准是新语言实际成片通过既有质量门禁。

证据索引：evidence:observations。它关联三个长期案例及真实视听观测，原始失败、用户认可与同一 Agent 自审分别保留。背景分离无损、任意画面自动去字和固定费用均未由这些观察证明。
