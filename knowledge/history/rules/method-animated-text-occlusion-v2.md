# 动态文字：对象保护、完整擦除范围与实际编码边界

适用于动态文字、移动字幕和文字与前景重叠的素材。继承 v1，并结合新源的成功修正及失败反例。方法可跨视频使用，坐标、阈值、遮罩和验收结论不跨源复制。

1. 先识别文字、图标、箭头、人物和嵌入照片的对象关系。相同颜色或相连区域不等于同一对象；前景手部与缩略图中的肤色也应分开。明确保护区域，避免文字擦除或新字覆盖前景。
2. 擦除范围覆盖文字进场、放大、稳定、重叠、出场、描边和阴影；擦除区间与新字显示区间分别记录。先检查不含译文的底片，再检查目标字层；不能靠新字遮住旧字残片。
3. 已知固定帧率时，以整数帧明确起止边界与区间是否包含末帧，避免四舍五入秒数造成一两帧残字。变帧率素材先使用实际时间戳映射，不能盲目用帧号除以固定帧率。实际编码后核对转场前后、首尾和连续运动帧。
4. 使用真实目标文字系统检查字形、透明度、描边、阴影和保护区；较长文本可调整换行、字号或精炼表达，但保留广告含义。手机界面文案与口播字幕分别排版，不互相遮挡。
5. 修补后检查衣服、头发、手指和移动物体是否出现柔化、重影或色块。OCR 未检出文字不证明修补合格；颜色阈值和局部修补模型均需按新场景复验。无法达到质量门禁时保留 revise。

证据：evidence:observations。本批 1-2 的帧边界修正、3-1 的前景/界面修正提供正向观察；1-1、4-2 的纹理与重影问题保留为反例。精选画面说明判断方式，不等价于完整逐帧录像。未证明通用纹理恢复、任意半透明艺术字或跨模型效果。
