# 请求总预算与逐笔费用

用户确认首版总计最多60 credits，后续真实复用请求新增总计最多40 credits，均为上限而非应花额度。一次请求的全部语言、模型、分析、配音、去字、复核和返工共用总额；不得通过新建run、批次、子任务或派生短片扩大额度。重试和修订仍是原请求。来源：`evidence:request`。

主控从真实用户消息登记请求预算，各执行任务绑定同一账本；派生片继承父任务。只有用户后续明确提出新复用需求、旧账已对清时才登记新的40额度，子Agent不得编造新用户请求。已授权本项目预算内自动使用KIE，不必逐对话重复确认；该同意不扩展至其他供应商或新部署的其他拥有者。

每笔调用在外发前预留，保存源绑定、模型、任务或响应ID、状态与实扣证据，失败也记录。网络结果不明先对账，不自动重发；unknown继续占位，不当零费用。供应商实际计费可能超过估价，本地门禁不等于远端账单硬限额。旧账、当前新增费用和未结算占位分别报告，复用已付费结果不重复计费；删除run不能重置额度。

同源后续语言可复用仍适用的解析、无目标文字底片和背景分轨；译稿、目标配音、字层、时轴与成片评审分别建立。平均成本只有在共享准备适用且新增费用较低时才会下降，不把单片成本当通用报价。

保留此前已确认的原位透明文字要求：字体、字重、色调、清晰度、运动和遮挡应接近原屏幕；按钮轮廓和图标保持原样。图标列为保护区域，较长标签不得占入；艺术字体使用包含目标语字形的字体或透明字形资产并逐字检查。来源：`evidence:prior-policy`。本条替代旧预算政策，旧原话和历史账本保留，不改变质量要求。
