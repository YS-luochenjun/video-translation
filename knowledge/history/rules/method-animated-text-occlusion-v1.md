# 动态文字：检查完整运动范围、风格和前景关系

适用于实例清单含文字运动轨迹的广告。该方法归纳三个源素材的开发观察；每个新素材重新测量，不复制示例的阈值、遮罩或字体尺寸。

1. 按实际对象和遮挡关系分开文字、图标、箭头及背景。颜色相连不等于同一对象；先确认前后关系，再选择分割和合成方法。
2. 在进场、放大、稳定、重叠、出场及末帧检查源文字的完整范围，包括描边、阴影和被裁切字母。源字擦除窗口与目标字显示窗口分别记录。
3. 在加入目标文字前检查底片和前景边缘，再逐实例重建必要的颜色、层级、尺寸与运动。文字围绕图标被错误拆分、残字跟随前景、统一配色损坏源风格都应触发局部返工。
4. 查看实际编码后的边界与连续帧，并按既有逐实例质量门禁审查。OCR用于定位和辅助，未识别到文字不等于画面没有残字。

证据索引：evidence:observations。观察包含成功修正和失败评审，并不证明复杂运动背景、任意艺术字或视频模型可以稳定自动完成。半透明素材、软边及新对象关系需单独检查。
