# 已被替代的知识

这里保存仍供现行规则、源限定案例、待审事项或在制计划引用的旧版本，以及有复用价值的观测和失败证据。过往场景中的路径可以作为来源标签。无实际用途的旧正文按知识合同清理，清理结果记在本地回执。

当前版本由 [方法索引](../index.json) 和 [源案例索引](../cases/index.json) 的 `status`、`superseded_by` 决定。正常 `context` 只读取有效条目，不把本目录作为候选方法集。

结构迁移与哈希对应见 [整理记录](../curation/structure-20261022.json)。现行预算以 [请求总预算](../rules/user-language-budget-60-20261026.md) 为准；旧额度不构成新调用授权。

仅目录路径变更的原始正文保存在 `path-migrations/`，对应迁移记录位于 [目录迁移记录](../curation/layout-migration-20261022.json)。它们是当前条目的原文快照，不代表新增规则或重新验收。
