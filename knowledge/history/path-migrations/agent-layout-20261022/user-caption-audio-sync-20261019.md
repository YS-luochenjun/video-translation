# 用户确认：口播与对应字幕统一

来源：用户2026-10-19原话“目前音频和字幕不统一，是否是可以修改的。先判断，告诉我”；随后“好的，先进行Agent项目的修改，吧这部分内容（字幕音频同步）加入。除了这个内容，目前视频还可以，知识还可以”。完整范围记录在 `evidence:ref-001`。

项目执行规则见 `docs/contracts/captions.md`。口播和对应字幕来自一份最终稿，按实际译后混音时间排字，最终同时审查成片声音与画面。独立标题、按钮、UI按自己的语义和画面时间翻译。背景音乐/音效继续保持，不能为追字幕而拉伸整条音乐。原语言文字的擦除与译文出现是两条时间约束。

已观察到的失败：中文口播“手势翻转棱镜特效怎么做……跟我一起学”与字幕“如何制作……跟我学”不一致；字幕沿用英文节奏，晚于中文声音结束。音频单独评审无法发现字幕问题。以上作为失败签名保留；新门禁的合成回归不证明该真实样片已经修好。

这是用户明确要求的项目行为，不是公司跨项目审美偏好；当前默认同步阈值是开发参数，仍需后续真实视频和用户反馈校准。当前新视频没有重测，自动强制对齐引擎尚未集成。继续使用已确认的预算与复用规则。
