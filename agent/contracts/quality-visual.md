# 实际成片视觉质量与证据

总入口见 [quality](quality.md)。

## 默认实用视觉标准

先按[原位替换政策](../../knowledge/rules/in-place-text-replacement-v2.md)核验任务是否做对：原语言应译文字清除后，译文在原位置按原视觉大小和样式出现。系统性保留英文并另加底部译文属于未完成原位替换，不能解释为普通修复残影、字体差异或best_available；用户已退回的实际版本及共用问题底片须登记quality-hold，修复后重新核验再扩语言。

按[自然去字合同](../../knowledge/rules/content-aware-text-restoration-v6.md)逐实例选路并查原片/无字底片/译片。默认目标是恢复背景与源视觉语言，透明度/羽化不是达标依据。简单底面自然重建，复杂运动/遮挡评估Wan；困难例外与停止证据只由该合同维护。保留以下正常播放容差和有界完整输出，制作路线约束与有界尽力后的提交资格分别判断。

用户明确禁止新增实心遮罩/底条、色块与硬边补丁盖字，制作时不能用minor或best_available作为主动盖字理由；尽力后仍有普通修复痕迹，按有界提交合同披露并提交，不能仅因不完美阻断。透明羽化局部模糊仅限特别困难且有真实自然修复失败/风险证据的兜底；单纯半透明色块不属于此例外。快速与严格均逐实例核验text_restoration_review及当前成片capture；内部处理掩模不属于可见遮挡。

先以正常速度、完整构图判断观看影响，再用原尺寸局部定位。轻微纹理变软、颗粒差异、很小的接缝或字体装饰差异，只要正常播放不显眼、不影响主体/信息/动作，可记录为 minor 后通过，停止为逐像素一致返工。只有暂停放大才易发现的差异，不单独构成失败。

审核优先看主标题、卖点、产品操作所需的指令、片尾 CTA、口播及主体连贯性。相机菜单等次要界面仍按实例检查。完成原位翻译、译文清楚且正常播放无影响时，切镜附近一闪而过且读不出原语单词的边缘残影可登记为普通小瑕疵。记下实例、时间段与观察，随当前成片审核。关键操作按钮、持续可读的原字、整项漏译和系统性双语叠字仍按原门禁处理。

- 5分：自然，未发现明显修复痕迹。
- 4分：局部轻微差异，正常观看基本不受影响。
- 3分：少量修复痕迹，正常播放不分散注意，信息、主体和运动完整；默认可接受。
- 2分：正常播放明显干扰，例如突兀补丁、持续闪烁或接缝；需要修复。
- 0–1分：严重失真、关键对象损坏或不可用。

快速审核保留八项基本检查，另在 `visual_finish` 写0–5分、正常播放观察、实际证据及瑕疵时间/严重度；视觉至少3分，major/critical阻断。minor只用于外观差异，不能覆盖基本检查失败。证据不足保持未审。严格保真另行选择，继续完整逐实例门禁；修改标准不自动把旧候选改为通过。

硬性缺陷包括必译内容残留、发布者水印或匹配片尾商标遗漏、产品/品牌/报价含义错误、译文提前或延后、不可读/闪烁、外语人声残留、非目标内容明显变化。水印首末及片尾同标均查实际成片。硬性缺陷不能被总体美观分或 minor 标签抵消，边界后完整输出仍披露残留。次要界面切镜残影如实保留去字检查结果，发布裁定按 Fireplay 证据规则记录。

`quality` 机器检查成片尺寸、时长、音轨与实际信号、源/请求/清单/计划/视频绑定、评审覆盖及分数。声音约定、波形核验与译后音频逐项审查见 `agent/contracts/audio.md`。语义和风格由有署名的评审判断；脚本不能证明评语真实。评审必须使用实际成片证据，标明同一 Agent 自审或独立评审。

口播字幕使用 [agent/contracts/captions.md](captions.md) 的独立门禁：共同定稿、逐片段内容、实际音频/画面时间和证据绑定都须通过。缺少分类或实际视听审查、漏词、时间偏差超标、配音或字幕变更后复用旧报告均会打回，不能由高分抵消。场景标题、按钮不要求逐字复述口播。

`config/quality.json` 的 `caption_sync` 给出当前开发阈值：起点最大偏差0.20秒、终点0.25秒，画面相对计划最大偏差0.034秒（当前30fps约一帧）。这是可调整的工程默认值，尚未通过遮蔽测试确定公司标准；更明显的节奏或语义问题仍由评审打回。

评分0–5分：翻译30%、画面保持25%、时序20%、音频15%、广告风格10%；默认总分80以上且无硬性缺陷。无口播时音频维度评保留是否正确，不能声称验证了配音能力。

验收每个文本实例：内容正确、原字已清除、区域对齐、出现/消失正确、持续可读；保留项验证保留理由。按[目标语排版](../../docs/source-typography.md#目标语排版由-codex-决定)逐语核对实际编码帧的分行、视觉大小、位置、遮挡及该书写系统的字形和阅读方向；不自然断行、孤字、明显过小、附标裁切或 RTL 乱序须修正。代表语言的评审不能代替其他语种。用户明确要求翻译的产品标题不能沿用默认品牌保留例外。类似 `Family Time` 的主标题和图标内标题要分别记录。每个人声片段核对意思、语种、时长、响度与衔接。

#### 标题与转场审核

片头、主标题、片尾CTA、结束卡文案及花字按[源文字样式](../../docs/source-typography.md#标题花字与艺术字优先还原)优先审查。每个目标语种以实际编码成片和原片对照，记录清晰度、色彩鲜亮程度、字形风格、描边阴影层次、视觉大小、构图与运动，并核对入出场及相邻原生帧。使用ImageGen艺术字时额外核对实际目标字形、透明边缘及原片保护区域。正常播放可见的标题模糊、暗淡杂乱、漏帧或明显风格失配须按有界返工处理；已存在的明确质量异议逐项核验修复后才可解除。

参照 MOG-20261127-026 的返工反馈，对标题重影分别核对两处。先看原片和无字底片，确认原字、描边和出入场残影已清除。再看当前成片，确认译文字面、各层描边和阴影符合设计，尤其检查多行基线与转场是否叠出第二套字形。每语种在正常速度播放对应区间，并用原尺寸帧定位问题。记录成片哈希、时段和观察，抽帧拼图用于定位。译文重影、描边错位或模糊导致核心文案难读时，用 `unreadable_core_copy` 登记严重发布缺陷，该版本不得按 `best_available` 放行。原语残留和有效质量异议沿既有门禁处理。源码排版方法见[渲染时的工程核验](../../docs/source-typography-render.md#渲染时的工程核验)。

#### 逐实例与底片审查

严格模式涉及文字替换时，执行 [逐实例去字与呈现审查](../../knowledge/rules/neutral-visual-and-animation-gate-v4.md)。`visual-evidence`生成原尺寸对照和pending模板；按实例提交实际观察后，底片、代表语言和最终交付分别核验。`quality`必须通过`text-visual-audit.json`及其逐实例观察的版本、覆盖和证据校验；缺项、fail/pending、动态帧缺失或整组重复套话不能由总分抵消。生成证据不自动填写pass。操作见[视觉门禁](../workflows/visual-review.md)。程序核验证据合同，视觉判断仍由真实审查负责。

固定排版通过实际字体字形测量，`protected_regions` 不得被覆盖。动态文字按实际轨迹和转角排版，区域合成只限制模型影响范围，不保证遮罩内的去字和背景正确；OCR 每0.1秒采样仍可能漏一帧，须补查首次/末次出现。所有本地修复有版本、输入/输出哈希和独立操作记录，不覆盖旧视频和旧评审。

背景音乐不是口播，配音不等于口型同步。外部音频理解、本地 OCR/ASR、分轨和 TTS 已有真实试验；识别候选不等于完整清单，分轨不等于无损分离。口型与复杂去字仍未稳定通过。更贵模型的成功回执不能覆盖残留英文、局部糊化或未核实音效。

用户纠正或复现推翻旧通过后，追加绑定实际成片/底片的quality-hold，保留原评审作为历史。当前交付和复用资格由原质量记录与后续异议共同决定，不能只读旧pass。操作及迁移边界见 `agent/workflows/quality-feedback.md`。原尺寸局部和连续运动检查须支持判断，缩略拼图不可单独证明背景干净或运动保真。

新快速计划的写字前底片与逐实例三路证据绑定，按[快速交付](../workflows/fast-delivery.md)执行。先单独看无字底片，再看新字：新字覆盖住旧字、模型任务成功或掩模外像素一致均不能证明去字成功。特别检查彩色强调、描边、半透明阴影、字入出场及原位之外的残影。泊松融合会采用供体梯度；供体仍含文字、选区漏掉效果或边缘含旧笔画时，换上新字仍可能透出原文。算法名和白色像素阈值不是识字或清理验收。
