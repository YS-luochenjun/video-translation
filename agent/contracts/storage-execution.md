# 存储执行、重复保存与结案

总入口见 [storage](storage.md)。

## 执行与重复保存

同源接入与解析恢复使用核验后写时复制（macOS 文件系统支持时），否则回退独立副本；保持可独立修改，不对可写源解析文件使用硬链接。生成字体按源哈希、真实字面及渲染转换身份复用现有 run 内已经生成的字体；索引仅记录可重建位置与哈希，源 run 回收后按需重建，不额外保留永久字体副本。确认替换片已审核通过后，通过既有 `run-prune-versions` 及时回收明确被替代且无活动依赖的旧视频；不在制作中仅凭名字或年龄自动删除。

执行器先检查活动锁，冻结候选路径、文件元数据、完整策略、索引及保留任务的依赖。独立保全必要文本记录，核对指纹后删除；归档从读取源文件到登记索引全程共用run锁，但不撤销原结案状态；结案生产者、新任务及归档均在取得自身锁后再次检查全局清理锁。在制任务的跨run引用按传递关系保护，指纹变化必须重新预览。知识审计前后通过；未知费用保留原预留、真实任务ID和响应，删除媒体不结清费用、不改变质量异议或用户验收。

- 同一需求／语言／任务只有一个默认final入口；相同归档重试不新增copy、backup、final2，不改变业务身份或首建时间。
- 成片必须脱离run仍可读，不能硬链接到可变run。不可变包内相同SHA256资产及正式展示优先硬链接；不支持时复制并校验。禁止原地修改展示文件，改版必须重新制作并原子替换。
- 相同源解析按哈希和提取参数核验复用。源观察有修订时，保留独立清单和观察正文。同一源及提取参数下，字节相同的缓存资产在不可变快照间优先硬链接，不链接可修改的run。快照可各自核验和到期。新语言仍独立定稿、配音和审核。需要修改的副本放所属work/runs，禁止额外整目录备份。默认lean没有源／准备资产恢复资格；archive-verify通过只证明包完整，不等于可恢复生产。
- 候选片转最终片及经批准的同源底片复制在 macOS 优先采用写时复制，保留独立文件并核验字节。相同成片重试复用现有文件，其他文件系统可用普通复制。同源底片引用目标任务已核验的源片。
- 新版成片总览用一次解码生成分页拼图及一张单帧。分页索引记录采样时间和范围。既有逐帧总览继续沿原布局恢复，首尾、镜头接缝、字幕及全幅实际审核证据保持原覆盖。同一视频版本中由同一抽帧结果产生的证据标签可共用不可变图片。
- 已结案缓冲期允许回收执行器登记的废弃无损母版。仅处理整片对应单镜头且新版底片通过完整时长及评审核验的任务。旧母版须早于当前底片、哈希匹配、未获批，且无本任务或其他保留任务的路径或哈希引用。保留配方、来源和审核记录。其他产物走常规结案或明确的版本清理流程。
- 失败或被替代的渲染，等同一任务的当前正式替换片通过质量检查、独立包核验且无在用引用后，即可用 `run-prune-versions RUN SPEC` 清理，无需先生成完整恢复副本。规格填写 `replacement_sha256`、旧版路径和哈希、判定理由、必要的文字记录及证据范围。确有复用价值时才随 `evidence` 保留局部截图或声音，普通返工可省略。执行沿用预览指纹和本机授权。仍在排查或只有 `best_available` 的任务沿用常规结案与清理条件。
- 知识只独立保存有用途的必要对照，不复制整片作永久备份；不跨公私或授权范围去重。临时副本登记用途和退出条件，保全记录不复制所有待删视频。
- 已核验上传、入库、素材详情和绑定回执，且重新计算的媒体哈希匹配时，归档跳过 `work/runs` 中的临时 Base64 上传参数文件。实际回执和未知操作的材料继续保留。
- 清理后移除空展示目录。回执分别报告逻辑字节和磁盘实际净变化；硬链接及并发系统写入下两者不同。当前没有全项目跨包物理去重，不作此宣称。

## 结案与一次性重置

外部提交和必要记录完成后执行`maintain RUN --close`。本机已授权的新布局核验独立交付后写入正式视频哈希结案标志；不再额外建立永久整片恢复副本。旧逐run入口仍走run-preserve → run-delete预览及指纹，不把生命周期执行器当force开关。

storage-reset只适用于用户当前明确确认所有旧任务已完成并要求清空、且本机另有一次性reset_existing_data授权的情况。它可清空runs/work/outputs/media，保留知识、state、费用、平台历史、配置、Git与安装资产；执行后消耗许可。定时入口永远不调用reset，本次优化不执行重置、不删除当前生产数据。
