# 遮蔽测试

1. 用相同源片、目标语言、规格和预算制作可比候选。保留失败和成本；不同路线的动作重建不能只比较画面好看。
2. `blind freeze RUN candidate1.mp4 candidate2.mp4` 随机映射 A/B，去除容器元数据，冻结文件清单与哈希；来源映射放 reveal，不给评审上下文。
3. 新评审上下文只读 blind/package、源片和同一评分标准。填写 blind/review.json；检查字面内容、时序和广告含义，并写理由。可见水印、品牌或画风可能泄露来源，须记限制。
4. `blind verify RUN` 验证包未变；`blind reveal RUN` 仅在全部候选已评分且指定胜者或平局后揭示。
5. 揭示只产生比较证据，不自动升格为公司偏好。偏好确认仍按 knowledge 规则执行。

这是流程遮蔽，不是安全隔离：同一文件权限下的 Agent 技术上能读取 reveal。首次开发没有伪造独立盲评；真正实验应使用不含制作者过程与映射的新上下文或独立评审者。
