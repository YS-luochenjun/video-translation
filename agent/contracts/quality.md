# 成品质量

每条视频的首尾音频必须按[开头残音与片尾口播检查](../../knowledge/rules/audio-head-tail-review-v1.md)分别核验原片和实际编码成片，并记录证据及结论；快速与严格均适用。缺检查保持未审，已确认漏译/残留原语不能作为普通瑕疵放行。远程主备仅因调用故障均不可用时，按[音频异常交付](audio.md#独立配音与转写)沿用完整 TTS，正式输出不冒称质量通过。

唯一综合分数配置：`config/quality.json`；快速视觉容差在 `config/fast-delivery.json`。2026-10-23 项目用户授权降低轻微视觉瑕疵的严格度，综合门槛由85调整为80；这是项目用户授权，不代表另有公司验收。历史失败与通过记录保持原结论。

质量门禁用于重试与“质量通过”标签；用户同时要求[最终必须输出](../workflows/always-output.md)。未达分数时保留 revise，在有界返工后用 finalize 交付带瑕疵的完整翻译视频，不把分数不足作为不输出视频的理由。

模式分支的统一入口为 [文字与运动检查](../../knowledge/rules/neutral-visual-and-animation-gate-v4.md)：fast 用基本审核及风险区证据；strict 增加完整逐实例连续帧审计。共同内容、音频和字幕要求均保留。

## 制作优先级

2026-11-26 用户明确要求适量优化、分清主次、控制单项返工时间和资源。下面的顺序用于安排制作与返工，同一级按原片实际信息载体、用户具体要求和正常播放影响排序。

| 优先级 | 观察与处理重点 |
| --- | --- |
| 必须先保证 | 翻译内容准确完整、产品信息正确、原语清除、必要配音完整可懂、画面主体与原有动作可用、没有严重音画错位；执行现有质量及发布门禁。 |
| 优先改善 | 多语言自然断行与字号、片头主标题及片尾CTA的清晰度、人物声线年龄/性别/情绪与原片匹配、BGM与口播平衡、音乐音效连续、实际字幕与声音时间一致。按实际观看影响优先处理。 |
| 适度优化 | 细微字体装饰、局部纹理、轻微色彩与音色差异、正常播放不显眼的动效或口型细节。达到可接受效果即收口。 |

明确反馈的问题优先于其他普通优化。质量检查与返工投入分别判断，全部语种仍按既有证据合同审核。试验、停止及交付按[有界改进循环](../workflows/continuous-improvement.md)执行。

## 新制作与返工的双域审核

2026-11-26 用户反馈 APC-20261126-098 修复文字后仍存在音频问题。每次新制作及单项返工均须对原片和当前实际编码成片执行文字、声音两域的审核，包含复用的旧字层和音轨。明确异议决定优先修复范围，其他区域按正常播放影响检查；旧素材未被驳回或沿用旧成片不构成当前审核证据。

- 文字：优先验证片头、主标题、片尾CTA和艺术字，再核对普通文案、UI及口播字幕的完整翻译、自然分行、字号、原位还原、清晰度与运动。按[源文字样式](../../docs/source-typography.md#标题花字与艺术字优先还原)选择复杂艺术字和普通文字的制作方式。
- 声音：对照[联合音频制作与返工验证及原片音量基线](audio.md#联合音频制作与返工验证)，确认原片各声音事件、目标语角色声线、完整口播、实际时间、BGM与音效连续性和口播相对响度。复用旧混音时先核验是否已有适用的分轨、电平与实际成片审核证据，必要时补测当前音轨。发现普通文字返工之外的实际音频缺陷，也在授权和剩余返工范围内局部修复；音频返工同样检查原有文字和标题。
- 代表片先合并两域检查再扩语种，最终逐语核对实际成片。复用同源基线及现有证据，按媒体哈希和实际改动检查有效性；供应商故障及证据缺失按现有合同披露。已证实合格的资产直接复用，正常播放可接受即收口，所有改善共享原有试验、预算和返工次数。
