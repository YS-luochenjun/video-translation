# 成品质量

唯一综合分数配置：`config/quality.json`；快速视觉容差在 `config/fast-delivery.json`。2026-10-23 项目用户授权降低轻微视觉瑕疵的严格度，综合门槛由85调整为80；这是项目用户授权，不代表另有公司验收。历史失败与通过记录保持原结论。

质量门禁用于重试与“质量通过”标签；用户同时要求[最终必须输出](../workflows/always-output.md)。未达分数时保留 revise，在有界返工后用 finalize 交付带瑕疵的完整翻译视频，不把分数不足作为不输出视频的理由。

模式分支的统一入口为 [文字与运动检查](../../knowledge/rules/neutral-visual-and-animation-gate-v4.md)：fast 用基本审核及风险区证据；strict 增加完整逐实例连续帧审计。共同内容、音频和字幕要求均保留。

## 默认实用视觉标准

按[底面与运动难度](../../knowledge/rules/content-aware-text-restoration-20261026.md)逐实例选择自然修复或局部模糊兜底：简单背景收紧模糊使用，复杂运动/遮挡更早评估。路线允许不等于质量通过，仍按下列正常播放标准评分；不合格时沿用有瑕疵输出流程，历史结论不变。

先以正常速度、完整构图判断观看影响，再用原尺寸局部定位。轻微纹理变软、颗粒差异、很小的接缝或字体装饰差异，只要正常播放不显眼、不影响主体/信息/动作，可记录为 minor 后通过，停止为逐像素一致返工。只有暂停放大才易发现的差异，不单独构成失败。

- 5分：自然，未发现明显修复痕迹。
- 4分：局部轻微差异，正常观看基本不受影响。
- 3分：少量修复痕迹，正常播放不分散注意，信息、主体和运动完整；默认可接受。
- 2分：正常播放明显干扰，例如突兀补丁、持续闪烁或接缝；需要修复。
- 0–1分：严重失真、关键对象损坏或不可用。

快速审核保留八项基本检查，另在 `visual_finish` 写0–5分、正常播放观察、实际证据及瑕疵时间/严重度；视觉至少3分，major/critical阻断。minor只用于外观差异，不能覆盖基本检查失败。证据不足保持未审。严格保真另行选择，继续完整逐实例门禁；修改标准不自动把旧候选改为通过。

硬性缺陷：必译内容残留、产品/品牌/报价含义错误、译文提前或延后、不可读/闪烁、外语人声残留、非目标内容明显变化。硬性缺陷不能被总体美观分抵消。

`quality` 机器检查成片尺寸、时长、音轨与实际信号、源/请求/清单/计划/视频绑定、评审覆盖及分数。声音约定、波形核验与译后音频逐项审查见 `agent/contracts/audio.md`。语义和风格由有署名的评审判断；脚本不能证明评语真实。评审必须使用实际成片证据，标明同一 Agent 自审或独立评审。

口播字幕使用 [agent/contracts/captions.md](captions.md) 的独立门禁：共同定稿、逐片段内容、实际音频/画面时间和证据绑定都须通过。缺少分类或实际视听审查、漏词、时间偏差超标、配音或字幕变更后复用旧报告均会打回，不能由高分抵消。场景标题、按钮不要求逐字复述口播。

`config/quality.json` 的 `caption_sync` 给出当前开发阈值：起点最大偏差0.20秒、终点0.25秒，画面相对计划最大偏差0.034秒（当前30fps约一帧）。这是可调整的工程默认值，尚未通过遮蔽测试确定公司标准；更明显的节奏或语义问题仍由评审打回。

评分0–5分：翻译30%、画面保持25%、时序20%、音频15%、广告风格10%；默认总分80以上且无硬性缺陷。无口播时音频维度评保留是否正确，不能声称验证了配音能力。

验收每个文本实例：内容正确、原字已清除、区域对齐、出现/消失正确、持续可读；保留项验证保留理由。用户明确要求翻译的产品标题不能沿用默认品牌保留例外。类似 `Family Time` 的主标题和图标内标题要分别记录。每个人声片段核对意思、语种、时长、响度与衔接。

严格模式涉及文字替换时，执行 [逐实例去字与呈现审查](../../knowledge/rules/neutral-visual-and-animation-gate-v4.md)。`visual-evidence`生成原尺寸对照和pending模板；按实例提交实际观察后，底片、代表语言和最终交付分别核验。`quality`必须通过`text-visual-audit.json`及其逐实例观察的版本、覆盖和证据校验；缺项、fail/pending、动态帧缺失或整组重复套话不能由总分抵消。生成证据不自动填写pass。操作见[视觉门禁](../workflows/visual-review.md)。程序核验证据合同，视觉判断仍由真实审查负责。

固定排版通过实际字体字形测量，`protected_regions` 不得被覆盖。动态文字按实际轨迹和转角排版，区域合成只限制模型影响范围，不保证遮罩内的去字和背景正确；OCR 每0.1秒采样仍可能漏一帧，须补查首次/末次出现。所有本地修复有版本、输入/输出哈希和独立操作记录，不覆盖旧视频和旧评审。

背景音乐不是口播，配音不等于口型同步。外部音频理解、本地 OCR/ASR、分轨和 TTS 已有真实试验；识别候选不等于完整清单，分轨不等于无损分离。口型与复杂去字仍未稳定通过。更贵模型的成功回执不能覆盖残留英文、局部糊化或未核实音效。

用户纠正或复现推翻旧通过后，追加绑定实际成片/底片的quality-hold，保留原评审作为历史。当前交付和复用资格由原质量记录与后续异议共同决定，不能只读旧pass。操作及迁移边界见 `agent/workflows/quality-feedback.md`。原尺寸局部和连续运动检查须支持判断，缩略拼图不可单独证明背景干净或运动保真。
