# 角色声线选择

适用于需要生成或修复口播、对白、独白、旁白和片尾CTA的任务。通用执行及异常交付读[音频合同](audio.md)，当前可用模型读[模型分工](model-routing.md)。

## 源角色分析

先联看源画面与音频，逐角色记录身份、语音职责、可辨年龄段、性别、音色、情绪、语速和与其他角色的区别。不明确的属性记录不确定性。依据源角色的实际声音和表演选声。

| 角色 | 选声依据与实际验收 |
| --- | --- |
| 儿童（男孩、女孩） | 自然的儿童年龄感、较轻盈的音色、符合角色的发音与情绪；与成年父母对话时，听众能感知明显年龄差。 |
| 少年、少女 | 符合原片的成长阶段、活力和表达方式，年龄感介于儿童与成年人之间。 |
| 成年人物、父母 | 按人物实际年龄和性格选择成熟度、音色厚度和情绪；父亲与母亲各自保持稳定辨识度，母亲与女儿即使同为女性也须有明显年龄差。 |
| 老年人物 | 按原片选择适当成熟度、音色质感、节奏与情绪，保持自然表达。 |
| 独立旁白、片尾广告解说 | 按原叙事者选择性别、年龄感、清晰度和解说节奏，与剧情男女主的声音可辨；CTA保持原叙事身份和推广语气。原片明确同一人时保持一致。 |

## 候选选择及验证

1. 根据当前模型的实际支持声线、目标语言与供应商提供的声音描述或样音筛选候选。Gemini 使用实际支持的 `voice_name`，ElevenLabs 在 `voice` 中填写实际支持的声线ID，保留角色、模型、标识和选择依据。优先采用同模型、同语言且经过实际验证的历史样音。
2. 结合相邻角色台词一次比较各候选的年龄感、音色质地、音高范围、共鸣、发音节奏及情绪。音量独立按混音需要调整。不同名称、不同ID、单独的音高变化均不足以证明角色匹配。
3. 代表语言先生成正式定稿中的代表性相邻对白及片尾旁白，保留可直接用于制作的合格配音。比较实际原声与目标音频，确认自然年龄差、发音、情绪和人物辨识度后扩展。控制 AI 无直接音频感知能力时，使用实际音频的远程复核或人工听感证据，区分测量、模型判断和人工听审。
4. 每语种核验实际编码成片的角色声线。出现母女、父子、主角与独立旁白声音混淆或年龄明显不符，优先替换受影响角色的全部台词并保持该角色声音一致，再重混和对轴。沿用原预算、现有主备模型及有界返工次数，避免无目的重复试音。

## 结果记录

逐角色保留 `character_id`、`speech_role`、源声音观察、目标语言、实际模型和声线标识、生成音频及哈希、选择理由和成片复核结论，无法核实的属性标记不确定。默认远程比较对已辨认的多个角色检查 `gender_matches_source_characters`、`age_matches_source_characters`、`role_distinction_matches_source` 和音色一致性、易混淆角色。实际声线质量与调用可用性分别记录，按音频合同处理供应商故障。

剧情时间处理见[短剧声音事件](../../knowledge/rules/short-drama-audio-scenes-v2.md)，人物连续性和降级边界见[固定角色声线](../../knowledge/rules/short-drama-character-voices-v2.md)。
