# Codex 与专用模型

2026-10-22 项目拥有者明确要求：文字识别、翻译和图片直接处理交给 Codex；真实音频与必要的视频编辑保留专用模型。此要求替代旧的 RapidOCR 默认、GLM 补查及多视频模型选路偏好。可执行清单只维护在 `config/model-routing.json`，通过 `bin/va.ps1 model-routing` 查看；不对 Codex 设置费用门槛，KIE 请求仍受原有预算与任务账本约束。

## 职责

2026-10-23 用户进一步明确：尽可能由 Codex 发挥判断与执行能力，专用模型只承担真实音视频信号处理。Codex 负责内容理解、翻译、选路、图片编辑、提示词、调用参数、排版、程序操作、结果比较与返工决定。FFmpeg 等确定性工具仍由 Codex 调用，不必为裁切、混音、编码调用生成模型。脚本限制输入、预算、时轴与证据，不预设必须依次尝试的修复算法。Codex主导判断不等于用脚本替代适合的ImageGen图片编辑或Wan连续修复；本地插值、整块供体或模糊若产生残字/条纹/接缝，就仍是失败候选。

| 工作 | 当前执行者 | 调用条件 |
| --- | --- | --- |
| 文字识别、翻译、图片编辑与视觉审核 | Codex，图片编辑使用宿主图像工具 | 读取实际图片和项目知识后直接完成；方法由 Codex 按内容决定 |
| 真实音频转写 | Whisper small，带 VAD | 需要知道实际对白、语种或时间；无音轨或有效缓存可省略 |
| 音乐、人声分离 | UVR Inst HQ3 | 需要替换混合音轨中的对白；已有合格分轨可复用 |
| 音频理解、原音与成片比较 | Gemini Flash；按当前路由选择两个复核备选 | 无法听音、转写疑点、音乐/音效与对白保留需要补充证据 |
| 配音 | 路由配置中的 Gemini TTS 与已授权的 ElevenLabs 备选 | 定稿后生成目标语言声音，实际混音后建立字幕时间 |
| 视频模型编辑 | Wan 3.0 videoedit | 判断需要连续生成运动、纹理或遮挡时直接选择；无需先把图片/本地方法逐个试失败 |

## Codex 对专用模型的控制

调用前，Codex 根据实际输入确定目的、区间、允许改变的内容、保留对象、预期输出及检查方法；写入已有 packet、配方或定稿，不另建重复表单。返回结果是证据或候选，由 Codex 决定采用范围及是否返工。

| 能力 | 调用前约束 | 返回后判断 |
| --- | --- | --- |
| ASR | 输入实际音轨，按需要选语种提示和片段，保留 VAD、词级时间与置信度；不把预期译稿喂成识别答案 | 核对首尾、低置信度、数字/品牌和疑似漏句；空结果不代表无人声，疑点才用音频理解补证 |
| TTS | Codex 定稿并按[角色声线选择](audio-voice-selection.md)选声音、风格与语速；`tts-packet` 约束原样朗读、语种、顺序、无配乐/额外台词，程序核验与定稿一致 | 核对实际音频的完整性、发音、时长和衔接，再决定停顿、裁切或适度变速；字幕取实际配音时间 |
| 音频理解/分轨 | 明确输入是原音、配音还是混音，要求带时间的观察及不确定项；只替换所需人声区间 | 分别比较人声、音乐、音效及同步；模型总体评价不替代逐项观察 |
| Wan 3.0 | 输入真实源片段并绑定 reference_video_urls；提示词明确具体文字/区域、进出场与遮挡、保留主体/图形/镜头/时长；仅去字时不添加译文。视觉任务使用 audio:false，原音与目标配音独立保留和回混；不发送旧版 prompt_extend/audio_setting 字段 | 按源帧比较残字、主体、运动和接缝；可只采用有效局部。时长/帧率/覆盖不足时拒绝拉长或混帧凑齐 |

约束不等于模型保证遵从。正常播放可接受的轻微视觉差异按 [成品质量](quality.md) 记录并结束返工；漏译、主体变形或听不清不能降为轻微瑕疵。每次返工只改变有依据的变量；沿用原任务恢复、预算与重试上限，未知任务先查询。已有 ASR、配音和视频结果满足输入/定稿/哈希条件时直接复用。

Gemini 配音和音频复核遇到供应商故障时，按 [KIE 恢复流程](../integrations/kie.md) 和当前路由配置选择兼容备选。音频复核可用 Hydrogen 比较双轨，主备均发生调用故障时按[音频异常交付](audio.md#独立配音与转写)直接使用完整 TTS，不再强制转写或本地语义复核；NVIDIA 仅为独立转写证据路线。其他任务沿各自模型合同定位输入、定稿、遮罩、音轨或结果问题，在同一能力内有界修正，超出能力或预算时保留 pending。图片工具不可用时报告宿主能力缺失。图像生成工具由 Codex 宿主提供。

Kling、Veo、Wan 2.6、Seedance、ElevenLabs Turbo 2.5、旧 Gemini 配音路线、Suno、Gemini 音频 Pro、Piper、Whisper base 和 LaMa 保留历史证据读取/结果复用。旧任务查询、下载和已核验资产复用不重新提交模型。RapidOCR/GLM 本机安装与历史输出保留，旧 `bin/ocr.py` 入口转为 Codex 识字工作包。
