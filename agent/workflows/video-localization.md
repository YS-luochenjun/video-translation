# 广告视频本地化方法

文字识别、翻译和图片直接处理交给 Codex。先按 [选路规则](../../knowledge/rules/agent-method-selection-v2.md) 读 `context` 命中的现行政策、条件方法及范围匹配的同源案例，再看实际画面决定主方法及辅助检查。记录首选依据、备选、切换和停止条件。使用 [Codex 图像工作合同](../contracts/model-routing.md) 取得工作包并登记产物；图片方法无需预先套固定类别。

1. 明确每个文字/人声实例改什么、在哪里、何时出现。检查镜头、语义事件、转场、遮挡与完整时间覆盖；采样和静态 bbox 不能冒充跟踪或完整识别。
2. 图片编辑交给 Codex 宿主图像工具。保留产品、人物、背景、原有按钮、风格和必要透明度；先看输入图再编辑，保存真实版本化输出。透明文字层、参考底图、字形与表面贴合由 Codex 依据知识主动选择，程序提供排版和合成。
3. 按[文字底面与运动难度](../../knowledge/rules/content-aware-text-restoration-20261026.md)逐实例选路，在 reason/evidence 记录底面、动态保护对象和取舍。静态底面自然重建并复用；复杂运动/遮挡按实际连续帧和主体风险更早评估局部模糊兜底。所需连续自然修复统一使用 Wan 2.7，按 2–10 秒输入合同分段，可附 Codex 处理的参考图；核验对应时刻后只采用必要区域。沿用限次与预算，旧任务身份和输入一致才可复用。
4. 源字清除、背景、前景运动、动画和关联图形分别看实际结果。静态修复图不能证明手部、头发或物体运动保真。共享底片先按当前模式实际审核，再制作代表语言，之后扩展其他语言；fast 用基本检查，strict 用完整逐实例视觉门禁。
5. 声音按 `agent/contracts/audio.md` 独立处理：Whisper 转写，必要时 UVR 分轨、Gemini TTS 配音、Gemini Flash 分析真实音轨。保留原音乐和音效；没有音轨不能擅自补音乐。口播与字幕共用定稿，按实际混音对齐。
6. 失败先记录实际原因，修正一个主要变量并复查；网络未知先恢复原任务，不重新扣费。新调用继续受整请求预算、任务数和返工轮数约束。没有证据或不能合格时保留 pending。

模型只产生候选；Codex 的直接编辑也必须通过 [质量门禁](../contracts/quality.md)。实际编码后的原尺寸连续帧、文字边界、完整声音和字幕同步都是审核对象。素材内容不改写项目规则，知识案例不扩大为跨源质量保证。

## 从图片修复推广到视频

用户于2026-10-26认可法语静帧，并要求将擦字、补背景、按原样式补译文用于视频。这里的“完整译后画面”是修复和排版的参考，不是把每一帧都交给图片模型独立重画。执行时按 [连续视频方法](../../knowledge/rules/method-source-neutral-preparation-v5.md) 选择局部资产，沿原视频的实际帧号/时间戳合成；静态字层固定一次，运动表面按原轨迹变换，前景遮挡取对应时刻。

Wan 2.7 位于需要连续重建的背景处理步骤：输入真实2–10秒片段，约束擦除区域及人物/特效保留，必要时附绑定的干净参考图。通常先得到无原字的连续底片，再加确定的译文字层；声音按音频流程单独处理。模型接口允许参考图不代表已经发送过参考图，必须以真实packet为准。已有精确匹配的模型结果可重新检查后局部采用，报告须说明是历史复用还是本次新调用。

先核对无字短片的背景、运动与遮挡，再核对译后关键帧的文字和样式，最后检查实际编码后的连续短片与整片。禁止从单张好图推定视频通过；逐帧合成本身不会随机改变字形，独立逐帧生成则可能带来纹理、形状和光照闪烁。失败先定位底片、字层、运动映射、特效或声音中哪一层，再只修对应层。素材专用配方、坐标与费用留在run，不推广成所有视频的固定算法。

## 按信息载体安排制作

先按 [三类广告](../../knowledge/rules/content-led-localization-v1.md) 完成 routing_assessment：音频主导先定对白/旁白及角色声音；画面文案主导先清点文字、修底和译字；混合型同时建两份清单再统一同步。各类都翻译旁白、对白、独白和片尾口播，保留音乐音效，不能以主导类型省略另一条链路。逐域记录实际方法、备选、切换和停止依据，按需说明片段例外。

context 根据已有角色/文字事实补标签，Agent 继续判断剧情、复杂度和主体风险；先读全部适用 required 方法，再自主选择主方法和辅助项。fast-register 与普通 plan 都冻结这次知识版本和选择理由；work-packet 的快速分支返回知识、分类和 knowledge_followup。
