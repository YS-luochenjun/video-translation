# 后续质量反馈如何影响旧交付

文件可恢复、原评审曾通过、现在适合交付，是三个不同判断。用户的新反馈或可复现缺陷能够推翻视觉通过，但不应改写历史文件来掩盖误判。

1. 定位实际源、成片哈希和问题区间；保留用户原话、观察证据及绑定不确定性。
2. 使用 `agent/templates/quality-hold.json` 填写规格，执行 `bin/va.ps1 quality-hold SPEC`。规格和证据使用工作区相对路径；输入文件哈希必须匹配。共享底片本身有缺陷时另写一条 `asset_kind: neutral_master` 的记录，不能只标某一语言的成品。
3. 运行 `delivery-index` 刷新当前查看入口。历史manifest及评审不变；`library-find` 返回原status、当前effective_status、quality_holds、visual_reuse_holds和production_eligible。`availability=available`只说明包仍完整可恢复，不等于可用于制作。
4. 制作底片检查和deliver阻断有异议的实际哈希。即使修改旧批准布尔值、复制到另一个run、重新归档，仍无法用同一字节绕过。deliver也复核计划内底片，避免绕开正常render后交付新文件。
5. 修复版本使用新的字节和审核证据；新哈希不自动继承旧异议，也不自动通过。当前实现只追加阻断事件，不提供删除历史异议或一键重新批准原问题字节的入口。

用户后来明确认可已展示的确切成片时，先保留其实际发布评审，再用`fireplay-publication-review`登记绑定该视频哈希的`user_acceptance`。仅该需求的发布、绑定和完整提交核验可以采用这条认可；通用制作/复用异议、历史缺陷和内部质量结论继续保留。认可不覆盖其他语种、其他需求、缺失翻译/必需配音或无法观看的成片；认可之后的新异议仍阻断。不能把“继续制作/上传”的授权单独当作画面认可，也不能为改哈希而重新编码已被否定的相同画面。

`work-packet`发现旧完整输出已有异议时，返回`quality_feedback_requires_revision`及原异议，不再以“旧片已完成”提示结束返工；已有不同哈希候选时提示审查新版。导航保留原预算、已发生费用和返工上限，不自动授权付费重试，也不把新版自动认定为已修好。

记录及必要证据独立保存于 `knowledge/local/quality-holds/<源哈希>/<资产哈希>/`。清理run或交付库不会删除这些记录；完整迁移既有工作区时须携带knowledge/local。干净源码导出排除客户异议记录，通用反例和方法另存公开knowledge/examples，二者各司其职。单独旧交付包仍是历史快照，不能在丢失后续异议库后声称掌握最新验收状态。

记录具有来源、不可变事件ID和证据哈希。重复登记相同事件不重复累积；修改同一ID时报错，必要时追加新事件。记录缺失或被篡改时阻断当前用途，不静默恢复旧通过状态。

这个机制负责落实已经观察到的质量判断，不自动识别灰块、残字或错误运动。Agent仍须检查实际编码视频，分别报告自审、独立审查和用户验收。视觉缺陷不会自动否定已核验的声音、译稿或其他源素材。

## 局部返工与素材复用

先按返工正文、原需求关联和问题附件，逐原片、语种及区间定位异议。用旧绑定或可核验的交付包定位准确版本，核对当前原片版本、目标语、定稿、时轴和素材身份。制作前在现有返工记录中列出修复内容、可用旧素材及其来源和核验结果。有异议的旧资产沿上方流程登记。返工交付使用重新组装并评审的当前成片。

| 问题范围 | 优先保留和修复 |
| --- | --- |
| 标题、花字、遮挡或原文残留 | 保留已核验的同语种配音、混音和不受影响的字层。译文字层错位时重做字层。原字或补底有问题时修该底片区间。画面时轴改变时重查音画同步。 |
| BGM、音效或口播响度 | 保留已核验的画面、字层和合格的口播。优先用已有可用分轨重新混音。时轴及画面规格一致时可保留原视频流。 |
| 声线、发音、漏句或口播时序 | 重做受影响的口播片段，保留已核验的其他声音与画面。若词句、停顿或时长变化，重新对齐受影响的口播字幕、动态字层及镜头提示。 |

条件满足时直接使用已核验的分轨、字层和底片。只有旧成片时可提取合格的独立音轨或画面流，先确认其中实际包含的内容、可解码性和时间基准。缺失、不可验证或受共同缺陷影响的部分按需重建。多语共用的去字底片集中修好一次，按实际语种核对译字和声音。

代表片确认反馈已修好、复用部分仍合格后再扩语种。最终逐语对照原片、旧版问题区和当前实际编码成片，执行[声音与画面审核](../contracts/quality.md#新制作与返工的双域审核)，重验合成后的同步、首尾、转场与明确异议。可引用仍适用的旧素材证据，交付裁定绑定当前视频哈希。
